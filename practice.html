How to use this set

Do these with a pen. Reading a solution feels like learning and isn't. Every problem is self-contained — all the data you need is in the problem statement, as a table or a figure — so open the problem, close the laptop, and work it on paper first.

Then open one step at a time. Each problem starts with “Step 1 — what's actually being asked”, because on an exam the most expensive mistakes happen before any arithmetic: answering the wrong question. Attempt each step before you reveal it. If your answer matches, open the next one. If it doesn't, find where the two traces diverge before reading further — that divergence point is the thing you actually need to learn.

Every problem ends with a box titled “Why this is the exam version of this idea.” That box names the specific trap the problem was built around. Those traps are the real content of this page; the numbers are just the delivery mechanism.

Problem 1Sizing a warehouse state space warm-up

A delivery robot lives on an $8 \times 6$ grid of floor cells (all 48 cells are legal). The world contains:

  • the robot's cell — one of 48;
  • five parcels $f_1,\dots,f_5$, each either still undelivered or delivered — one bit each;
  • the robot's facing $d \in \{\mathrm{N},\mathrm{S},\mathrm{E},\mathrm{W}\}$;
  • a battery level $\beta \in \{0,1,\dots,20\}$ — 21 values.

Give the state representation and the state-space size for each of the following tasks.

  1. (a) The full world state.
  2. (b) “Drive to the charging dock in the corner.” Moves are N/S/E/W, each legal from anywhere, each costing 1. Battery is ignored.
  3. (c) “Deliver all five parcels”, battery ignored, moves N/S/E/W.
  4. (d) “Deliver all five parcels without the battery hitting 0”, where every move drains one unit.
Step 1 — What are we actually being asked?

Not “how many things are in the world”. The question is: which variables does this particular search problem read? A variable belongs in the state if and only if the goal test, the action set $\text{Actions}(s)$, the transition model $\text{Result}(s,a)$, or the cost function $c(s,a,s')$ consults it — or if it changes in a way that later affects one of those.

So run a four-way relevance test on each of $p$ (position), the $f_i$, $d$ (facing), $\beta$ (battery), once per task.

Step 2 — (a) and (b)

(a) The full world state keeps everything: $(p, f_1,\dots,f_5, d, \beta)$, size

$$48 \cdot 2^5 \cdot 4 \cdot 21 = 48 \cdot 32 \cdot 4 \cdot 21 = \mathbf{129{,}024}.$$

(b) The goal test reads only $p$. Moves are N/S/E/W regardless of facing, so $\text{Actions}$ does not read $d$. Cost is 1 per move, so $c$ reads nothing. Parcels are never read. Battery is ignored by assumption.

State $= (p)$, size $\mathbf{48}$.

Note how brutal that is: $129{,}024 \to 48$, a factor of 2688, purely by deleting variables nobody reads.

Step 3 — (c) and (d)

(c) The goal test now reads all five $f_i$ (“are they all delivered?”), and the $f_i$ change as we act, so they stay. $d$ and $\beta$ are still unread.

$$\text{State} = (p, f_1,\dots,f_5), \qquad 48 \cdot 2^5 = \mathbf{1{,}536}.$$

(d) Now “without the battery hitting 0” makes $\beta$ part of the legality of a plan, and $\beta$ changes with every move, so the transition model reads and writes it. It's in.

$$\text{State} = (p, f_1,\dots,f_5, \beta), \qquad 48 \cdot 32 \cdot 21 = \mathbf{32{,}256}.$$

$d$ is still out in every task, because nothing — goal, actions, transitions, costs — ever consults it.

Why this is the exam version of this idea

The trap is the facing variable $d$. It is listed prominently in the problem, it is part of the world, and it is irrelevant to every single task — so every product you write that contains a $4$ is wrong. The exam always plants at least one decoy variable, and it usually plants it in a task where a small rule change would make it relevant (if actions were “turn left / go straight”, $d$ would be back in, through $\text{Actions}$, not through the goal test).

Second trap: $2^5$, not $5$ and not $5!$. The state is a snapshot, not a history. Five independent bits give $2^5$ configurations; the order of delivery lives in the plan, not the state.

Problem 2Hand-trace BFS, DFS and UCS on one graph exam level

Start state $S$, goal state $G$. Edges are undirected; the number on an edge is its cost in both directions.

The state space graph
Successors are always generated in alphabetical order, and ties in the priority queue are broken alphabetically. All three algorithms are graph search: a state is never expanded twice, and the goal test happens when a node is popped, not when it is generated.

For each of BFS, DFS and UCS, give (i) the order in which states are popped off the frontier and expanded, and (ii) the path returned and its cost.

Step 1 — What are we actually being asked?

Three questions in one, and they differ in exactly one line of code: what the frontier is.

  • BFS — frontier is a FIFO queue. Pop order is by depth (number of edges), ignoring cost entirely.
  • DFS — frontier is a LIFO stack. To pop alphabetically-first, you push successors in reverse alphabetical order.
  • UCS — frontier is a priority queue keyed on $g(n)$, the cumulative cost from $S$. Pop order is by cost.

The adjacency lists, alphabetised:
$S\!:\!A,B$  ·  $A\!:\!C,D,S$  ·  $B\!:\!D,E,S$  ·  $C\!:\!A,D,G$  ·  $D\!:\!A,B,C,G$  ·  $E\!:\!B,G$  ·  $G\!:\!C,D,E$.

Step 2 — BFS

Pop $S$; enqueue $A,B$. Pop $A$; enqueue $C,D$ ($S$ already expanded). Pop $B$; $D$ is already queued, enqueue $E$. Pop $C$; enqueue $G$. Pop $D$ — nothing new. Pop $E$ — nothing new. Pop $G$: goal.

Pop order: $S, A, B, C, D, E, G$.

Returned path: $S \to A \to C \to G$, found at depth 3. Cost $= 1 + 2 + 8 = \mathbf{11}$.

BFS found a shallow path, not a cheap one.

Step 3 — DFS

Push $S$. Pop $S$, push $B,A$ (reverse alphabetical, so $A$ is on top). Pop $A$, push $D,C$ → pop $C$, push $G,D$ → pop $D$ (top of stack), push $G,C,B,A$ → after skipping expanded states, pop $B$, push $E$ → pop $E$, push $G$ → pop $G$: goal.

Pop order: $S, A, C, D, B, E, G$.

Returned path: $S \to A \to C \to D \to B \to E \to G$, cost $= 1+2+1+1+7+2 = \mathbf{14}$.

DFS returned the worst of the three. That is normal, and it is not a bug: DFS promises nothing about quality.

Step 4 — UCS

Track $g$ as you go. Pop $S$ ($g{=}0$); frontier $A{:}1$, $B{:}4$. Pop $A$ ($g{=}1$); add $C{:}3$, $D{:}6$ (via $A$). Pop $C$ ($g{=}3$); $D$ via $C$ is $3+1 = 4 < 6$, so replace the frontier entry for $D$ with $g{=}4$; add $G{:}11$ (via $C$). Now the frontier holds $B{:}4$, $D{:}4$, $G{:}11$ — a tie at 4, broken alphabetically, so pop $B$ ($g{=}4$); $D$ via $B$ would be $4+1=5$, worse than 4, discard. Pop $D$ ($g{=}4$); $G$ via $D$ is $4+3 = 7 < 11$, replace. Pop $G$ ($g{=}7$): goal.

Pop order (with $g$): $S(0),\ A(1),\ C(3),\ B(4),\ D(4),\ G(7)$ — note $E$ is never expanded.

Returned path: $S \to A \to C \to D \to G$, cost $= 1+2+1+3 = \mathbf{7}$.

Why this is the exam version of this idea

Trap 1 — “BFS finds the shortest path.” BFS finds the path with the fewest edges. Here that is the 3-edge, cost-11 route; the optimal route has 4 edges and costs 7. BFS is optimal only when every step cost is equal.

Trap 2 — the frontier replacement at $D$. The single most-missed line in UCS: when a cheaper path to a state already on the frontier is found, you replace the entry rather than adding a second one or ignoring it. Miss it and you return $S\to B\to D\to G$ at cost 8.

Trap 3 — goal test on pop, not on generation. $G$ was generated with $g{=}11$ while $C$ was expanded. If you had returned then, you'd answer 11. UCS only commits when $G$ reaches the front of the queue, by which point its $g$ has been improved to 7.

Problem 3Completeness and optimality, argued not recited exam level

Answer each with a one-line argument or an explicit counterexample. You may reuse the graph from Problem 2.

  1. (a) Is DFS complete on the Problem 2 graph? Is DFS complete in general?
  2. (b) BFS is complete when the branching factor is finite. Is BFS optimal on the Problem 2 graph? Give the cheapest counterexample you can.
  3. (c) UCS is optimal when all step costs satisfy $c \ge \varepsilon > 0$. What breaks if some edges are allowed cost $0$? What breaks if some edges are allowed negative cost?
  4. (d) Someone changes every edge in the Problem 2 graph to cost $1$. Does UCS now expand states in the same order as BFS? Does it return the same path?
Step 1 — What are we actually being asked?

Pin the definitions down before arguing. Complete: if a solution exists, the algorithm is guaranteed to find one in finite time. Optimal: the solution it returns has minimum total cost. These are different properties and a given algorithm can have one without the other — DFS-with-a-visited-set on a finite graph is complete but not optimal.

Note also that “complete” is a property of the algorithm + graph class pair, not of the algorithm alone. That is why (a) has two different answers.

Step 2 — (a) and (b)

(a) On the Problem 2 graph: yes, complete. The graph is finite (7 states) and we are running graph search with an explored set, so no state is expanded twice; the search must terminate, and it terminates having touched every reachable state, so if $G$ is reachable it is found.

In general: no. Two ways it fails. (i) Tree search on a cyclic graph: with no explored set, DFS can loop $S \to A \to S \to A \to \cdots$ forever. (ii) Infinite state spaces: even acyclic, DFS can march down an infinite branch (“keep adding 1 to the counter”) and never come back, even though the goal sits one step off the root.

(b) No. The counterexample is already in Problem 2: BFS returns $S\to A\to C\to G$ at cost 11, but the optimum is 7. The minimal counterexample is three nodes — $S\to G$ costing 10, and $S\to A$ costing 1 with $A \to G$ costing 1. BFS finds the 1-edge path of cost 10 and stops; the optimum is the 2-edge path of cost 2.

Step 3 — (c)

Zero-cost edges. Optimality survives — the proof of UCS optimality only needs $g$ to be non-decreasing along a path, which $c \ge 0$ gives you. What dies is the completeness guarantee in an infinite space: with a positive lower bound $\varepsilon$ on step cost, every cost contour contains finitely many nodes, so UCS eventually pushes past any finite cost. With cost-0 edges you can build an infinite zero-cost chain out of $S$ and UCS will expand it forever, never reaching the cost-1 contour that contains the goal. On a finite graph, zero costs are harmless.

Negative-cost edges. Now optimality dies outright. UCS assumes that once a state is popped, its $g$ can never improve — that is exactly why we are allowed to mark it explored and never reconsider it. A negative edge discovered later can lower the true cost of an already-expanded state, and UCS will never notice. (This is why you need Bellman–Ford, not Dijkstra/UCS, for negative weights. beyond syllabus)

Solution

(d) With all costs $1$, $g(n)$ equals the depth of $n$, so the priority queue orders by depth — which is exactly what the FIFO queue does, provided ties are broken in insertion order. So UCS and BFS expand in the same order and both return a minimum-depth path, which is now also a minimum-cost path. This is the precise sense in which BFS is the special case of UCS with unit costs, and the mirror of the fact that UCS is the special case of A* with $h \equiv 0$.

Why this is the exam version of this idea

The trap is memorising the table instead of the reason. Every row above has a condition attached, and the exam question is always built by deleting the condition: “DFS is incomplete” (only without an explored set, or in an infinite space), “BFS is optimal” (only for unit costs), “UCS is optimal” (only for non-negative costs). If you can produce the three-node counterexample for BFS in ten seconds, you have actually learned it; if you can only recite the row, you haven't.

Part (c) is the one people lose points on, because zero and negative break different properties — zero breaks completeness in infinite spaces, negative breaks optimality everywhere.

Problem 4A* trace: expansion order with $g$, $h$, $f$ exam level

Directed graph below; edge labels are costs, the boxed value under each node is $h$. Start $S$, goal $G$. Run A* graph search: priority $f(n) = g(n) + h(n)$, goal test on pop, ties broken alphabetically. List every pop with its $g$, $h$ and $f$, then give the path returned and its cost.

Graph with heuristic values
Edges: $S\!\to\!A(2)$, $S\!\to\!B(1)$, $A\!\to\!C(2)$, $A\!\to\!D(5)$, $B\!\to\!C(2)$, $B\!\to\!D(2)$, $C\!\to\!G(4)$, $D\!\to\!G(4)$.
Step 1 — What are we actually being asked?

An A* trace is bookkeeping, not cleverness. Keep three columns and never mix them up:

  • $g(n)$ — backward cost: what the path you actually took to $n$ has cost so far. A fact.
  • $h(n)$ — forward estimate: guessed remaining cost from $n$ to a goal. Given to you, never computed.
  • $f(n) = g(n) + h(n)$ — estimated total cost of the cheapest solution through $n$. This is the priority.

“Graph search” means: keep an explored set; never expand a state twice; if a cheaper path to a frontier state appears, replace the entry.

Step 2 — The first two pops

Insert $S$ with $g{=}0$, $h{=}5$, $f{=}5$.

Pop 1: $S$ — $g{=}0, h{=}5, f{=}5$. Generate $A$ ($g{=}2$, $f{=}2{+}4{=}6$) and $B$ ($g{=}1$, $f{=}1{+}4{=}5$).

Frontier: $B(f{=}5)$, $A(f{=}6)$.

Pop 2: $B$ — $g{=}1, h{=}4, f{=}5$. Generate $C$ ($g{=}1{+}2{=}3$, $f{=}3{+}3{=}6$) and $D$ ($g{=}1{+}2{=}3$, $f{=}6$).

Frontier: $A(6)$, $C(6)$, $D(6)$ — a three-way tie.

Step 3 — The tie, and the discarded path

Alphabetical tie-break: Pop 3: $A$ — $g{=}2, h{=}4, f{=}6$.

$A$ generates $C$ with $g = 2+2 = 4$. But $C$ is already on the frontier with $g = 3$. Since $4 > 3$, discard — do not add a second $C$.

$A$ also generates $D$ with $g = 2+5 = 7$, worse than the existing $g{=}3$. Discard.

So expanding $A$ changed nothing at all. That is A* correctly refusing to be tempted: $A$ looked as promising as $C$ and $D$ on $f$, and turned out to be a dead weight.

Pop 4: $C$ — $g{=}3, h{=}3, f{=}6$. Generates $G$ with $g = 3+4 = 7$, $f = 7+0 = 7$.

Pop 5: $D$ — $g{=}3, h{=}3, f{=}6$. Generates $G$ with $g = 3+4 = 7$ — a tie, so nothing improves.

Pop 6: $G$ — $g{=}7, h{=}0, f{=}7$. Goal test fires.

Why this is the exam version of this idea

The trap is pop 3. $A$ gets expanded even though it contributes nothing to the answer, because its $f$ ties with the useful nodes. Students who “shortcut” by only following the eventual solution path report five pops and miss $A$ and $D$. A* expands every node with $f < f^*$ and some of those with $f = f^*$; it does not magically know which ones matter.

Second trap: the two $g$-values for $C$ (3 via $B$, 4 via $A$). The exam wants to see you keep the smaller one and discard the larger. Writing $C$ twice in your table with two different $g$'s is the classic tree-search-in-graph-search-clothing error.

Third trap: $G$ is generated at pop 4 but not returned until pop 6. Goal test on pop.

Step 1 — What are we actually being asked?

Two different tests that students routinely merge into one.

Definition

Admissible: $0 \le h(n) \le h^*(n)$ for every $n$, where $h^*(n)$ is the true cheapest cost from $n$ to the nearest goal. This is a per-node test against the truth.

Consistent: $h(n) \le c(n,a,n') + h(n')$ for every edge $n \to n'$, and $h(\text{goal}) = 0$. This is a per-edge test, a triangle inequality, and it never mentions $h^*$.

Consistency implies admissibility, never the reverse. So (b) can fail while (a) passes — that is exactly what this problem is built to show.

Step 2 — (a) Admissibility

Compute $h^*$ backwards from the goal:

  • $h^*(G) = 0$.
  • $h^*(C) = 3$ (only edge $C\to G$).
  • $h^*(A) = 1 + h^*(C) = 4$.
  • $h^*(S) = \min\{\,1 + h^*(A),\ 3 + h^*(C)\,\} = \min\{5, 6\} = 5$.

Step 4 — (c) A* graph search on this graph

Insert $S$: $g{=}0,h{=}2,f{=}2$.

Pop $S$ ($f{=}2$). Generate $A$ ($g{=}1$, $f{=}1{+}4{=}5$) and $C$ ($g{=}3$, $f{=}3{+}1{=}4$).

Pop $C$ ($g{=}3, h{=}1, f{=}4$) — it beat $A$ on $f$. Mark $C$ explored. Generate $G$ ($g{=}6$, $f{=}6$).

Pop $A$ ($g{=}1, h{=}4, f{=}5$). $A$ offers $C$ at $g = 1+1 = 2$, which is better than the 3 we used — but $C$ is already in the explored set, so graph search throws it away. There is no frontier entry left to replace.

Pop $G$ ($g{=}6, f{=}6$). Return $S \to C \to G$ at cost $\mathbf{6}$.

The true optimum is $S \to A \to C \to G$ at cost $1 + 1 + 3 = \mathbf{5}$. A* graph search returned a suboptimal path.

Solution

(a) Admissible — every $h(n) \le h^*(n)$, tight at $A$.

(b) Not consistent. Violating edge $A \to C$: $h(A) = 4 > c(A,C) + h(C) = 1 + 1 = 2$.

(c) A* graph search returns $S\to C\to G$, cost 6; the optimum is $S\to A\to C\to G$, cost 5. A* tree search on the same graph would still return the optimum (it would regenerate $C$ via $A$ and win), which is exactly the theorem: admissible ⇒ A* tree search optimal; consistent ⇒ A* graph search optimal.

Diagnostic you can use on any trace: with a consistent $h$, the $f$-values of popped nodes are non-decreasing. Here they went $2, 4, 5, 6$ — non-decreasing by luck — but the underlying $f$ along the optimal path $S(2), A(5), C(3), G(5)$ drops from 5 to 3. That drop is the inconsistency made visible.

Why this is the exam version of this idea

The trap is believing admissible is enough. It is enough for tree search only. This problem is the smallest possible graph where the distinction bites, and it is the exact structure the lecture used: a node ($C$) reachable two ways, expanded early via the expensive route because its heuristic under-promised, then locked out of correction by the explored set.

The examinable phrase is “exhibit the violating edge”. Saying “it's inconsistent” earns nothing; naming $A\to C$ and writing $4 > 1 + 1$ earns everything. Also note that consistency is checked on edges — there are only four to check here, and checking nodes instead is the standard wrong move.

Problem 6Design a heuristic by relaxation, then prove it stretch

Pacman sits at cell $(1,1)$ of a $5\times 5$ grid — coordinates are (column, row), rows numbered top to bottom. There are walls (shaded). He must eat all three dots, at $(1,4)$, $(3,1)$ and $(4,4)$. Legal moves are N/S/E/W into a non-wall cell, each costing 1. The goal is reached when all three dots are eaten.

The maze
Pacman (gold) at $(1,1)$; dots (terracotta) at $(3,1)$, $(1,4)$ and $(4,4)$. Shaded cells are walls.
  1. (a) What is the state space for this problem, and how big is it?
  2. (b) Three candidate heuristics: $h_{\text{count}} = $ number of dots remaining; $h_{\max} = \max_{\text{dots }d} \text{Manhattan}(p,d)$; $h_{\text{sum}} = \sum_{\text{dots }d}\text{Manhattan}(p,d)$. Compute each at the start state.
  3. (c) Which are admissible? Prove the admissible ones by naming the relaxation. Kill the inadmissible one with a counterexample.
  4. (d) Which heuristic should you actually use?
Step 1 — What are we actually being asked?

The recipe the course gives for inventing admissible heuristics is: solve a relaxed problem exactly. A relaxation is the same problem with extra actions allowed (or constraints deleted). Because every legal plan in the original is still legal in the relaxation, the relaxed optimum can only be cheaper — which is precisely $h(n) \le h^*(n)$.

So for each candidate you must name the relaxation it is the exact solution to. If you can't name one, it probably isn't admissible.

Step 2 — (a) The state space

It is not just Pacman's position. The goal test reads which dots are eaten, and that changes as he moves, so it's part of the state:

$$\text{State} = (p,\ e_1, e_2, e_3), \quad p \in \{25 \text{ cells}\} \setminus \{3 \text{ walls}\},\ e_i \in \{0,1\}.$$

Size $= 22 \cdot 2^3 = \mathbf{176}$. Tiny, but the same construction with 30 dots is the $2^{30}$ blow-up from Chapter 1.

Step 3 — (b) The three values at the start

Manhattan distance from $(1,1)$, ignoring walls:

  • to $(3,1)$: $|1-3| + |1-1| = 2$;
  • to $(1,4)$: $|1-1| + |1-4| = 3$;
  • to $(4,4)$: $|1-4| + |1-4| = 3 + 3 = 6$.

So $h_{\text{count}} = \mathbf{3}$, $h_{\max} = \max(2,3,6) = \mathbf{6}$, $h_{\text{sum}} = 2+3+6 = \mathbf{11}$.

Step 4 — (c) Admissibility, one at a time

$h_{\text{count}}$ is admissible. Relaxation: allow Pacman to teleport to any cell for free; he still must step onto each remaining dot, and each such step costs 1. The optimal cost of that relaxed problem is exactly the number of dots left. Formally, every real plan that eats $k$ dots contains at least $k$ moves (each dot is eaten by entering its cell), so $h^* \ge k = h_{\text{count}}$. ∎

$h_{\max}$ is admissible. Relaxation: delete the walls (so movement is free Manhattan movement) and require only that the single farthest dot be eaten, ignoring the others. Any real plan must at some point reach that dot, and reaching it costs at least its Manhattan distance (each move changes the Manhattan distance by at most 1, and walls only ever make it worse). So $h^* \ge \max_d \text{Manhattan}(p,d) = h_{\max}$. ∎

$h_{\text{sum}}$ is not admissible. It double-counts shared travel. Counterexample right here: ignore walls for a moment and compute the true cost of the wall-free version of this very problem. The best visiting order is $(1,1) \to (3,1) \to (4,4) \to (1,4)$, costing $2 + 4 + 3 = 9$. All six orders:

Solution

(a) $(p, e_1,e_2,e_3)$, size $22 \cdot 8 = 176$.

(b) $h_{\text{count}} = 3$, $h_{\max} = 6$, $h_{\text{sum}} = 11$.

(c) $h_{\text{count}}$ and $h_{\max}$ admissible (relaxations: free teleportation / no walls and only one dot required). $h_{\text{sum}}$ inadmissible — it reports 11 where the true cost is at most 9.

(d) Use $h_{\max}$, or better, $h(n) = \max\!\big(h_{\text{count}}(n),\, h_{\max}(n)\big)$.

Key idea

Larger admissible heuristics dominate: if $h_a(n) \ge h_b(n)$ for all $n$ and both are admissible, A* with $h_a$ expands a subset of the nodes A* with $h_b$ expands. The max of two admissible heuristics is admissible (it is still bounded by $h^*$, since both arguments are) and dominates both — so you never have to choose between two admissible heuristics. Here $\max(3, 6) = 6$; on a state where only one far dot remains, $h_{\max}$ wins, and on a state with many nearby dots, $h_{\text{count}}$ wins.

Why this is the exam version of this idea

The trap is $h_{\text{sum}}$. It is the most natural thing to write, it is bigger (so it feels better), and it is wrong for a reason that has nothing to do with walls: the three trips share road. Any heuristic that adds up costs of sub-goals that can be achieved on the way to each other overestimates. The exam almost always offers a sum as a distractor next to a max.

Second trap: “prove it admissible” means name the relaxation and show every real plan costs at least this much. “It looks small” is not a proof. Third trap: forgetting that the dot-bits belong in the state — an $h$ that depends only on position cannot be right for a multi-dot problem, because two states with the same position and different dots need different estimates.

Problem 7Minimax value and the action warm-up

A two-player, zero-sum, turn-taking game. The tree below alternates MAX (▲, blue player, moves first), MIN (▼), MAX (▲), then terminal utilities — all stated from MAX's point of view. Compute the minimax value of the root and name the action MAX should take.

Depth-3 game tree

Step 1 — What are we actually being asked?

Two things, and the second is the one people forget. The minimax value is a number — the utility MAX can guarantee against an optimal opponent. The answer to the game is an action — which child of the root achieves that value.

You evaluate strictly bottom-up: every node's value is determined by its children, so you can never start at the root.

Step 2 — The MAX layer just above the leaves

Four MAX nodes, each taking the max of its two leaves:

  • $a = \max(5, 2) = 5$
  • $b = \max(9, 3) = 9$
  • $c = \max(4, 8) = 8$
  • $d = \max(6, 1) = 6$
Step 3 — The MIN layer, then the root
  • Left MIN $= \min(a, b) = \min(5, 9) = 5$
  • Right MIN $= \min(c, d) = \min(8, 6) = 6$

Solution

Minimax value of the root: 6. MAX should play Right.

The full annotated tree: leaves $5,2\,|\,9,3\,|\,4,8\,|\,6,1$ → MAX layer $5, 9, 8, 6$ → MIN layer $5, 6$ → root $6$.

Read the guarantee out loud: “If I play Right, then whatever MIN does, I end up at either $c=8$ or $d=6$; MIN will send me to $d$; from $d$ I take 6.” The 9 down the Left branch is unreachable against a competent opponent — MIN simply steers to $a=5$ instead.

Why this is the exam version of this idea

Trap 1 — the biggest leaf is a lie. The largest utility in the tree is 9, sitting under Left. Left is the wrong move. Minimax value is never “the best thing that could happen”; it is the best thing MAX can force.

Trap 2 — answering with a number when an action was asked for. The notes say this explicitly: “the number 4 isn't quite the answer we are looking for at the root… we need to select an action.” Write both: value 6, action Right.

Trap 3 — the layer alternation. With three plies, the layer directly above the leaves is MAX again, not MIN. Mislabel it and you get root $= \max(\min(5,2\,{\to}\,2), \ldots)$ and a confidently wrong answer. Count plies from the root downward before you start.

Problem 10Formulate a puzzle as a CSP warm-up

A department must schedule four seminars — Algorithms, Biology, Chemistry and Design — into the four time slots 1, 2, 3, 4 of a single day. The rules:

  1. Algorithms must finish before Biology starts.
  2. Biology must finish before Chemistry starts.

  4. Algorithms and Design share a room, so they cannot be in the same slot.
  5. Two seminars may otherwise share a slot (there are two lecture halls).

Step 1 — What are we actually being asked?

A CSP formulation is exactly three lists. Nothing else counts.

Definition — CSP

A CSP is given by variables $X_1,\dots,X_n$; a domain $D_i$ of allowed values for each $X_i$; and a set of constraints, each specifying the allowable combinations of values for some subset of the variables. A state is an assignment (possibly partial); the goal test is “complete and satisfies every constraint”.

The skill being tested: choosing variables so that the constraints come out binary (each touching at most two variables), because every algorithm in this unit — forward checking, arc consistency, AC-3 — is defined on binary constraints and a binary constraint graph.

Step 2 — Variables and domains

The natural choice: one variable per seminar, whose value is its slot.

$$\text{Variables: } A, B, C, D \qquad \text{Domains: } D_A = D_B = D_C = D_D = \{1,2,3,4\}.$$

The alternative — one variable per slot, valued by which seminar goes there — is worse here: rule 5 lets two seminars share a slot, so a slot-variable would need a set-valued domain, and the constraints stop being binary.

Note that rule 5 is not a constraint at all. It is the absence of an all-different constraint. Exam papers phrase absences as if they were rules, precisely to see whether you write a constraint for them.

Solution

Constraints (all binary):

Constraint graph
Every edge is one binary constraint. Note $A < B$ is directed in meaning but the graph edge is undirected — arc consistency will later treat it as two arcs, $A\!\to\!B$ and $B\!\to\!A$.

Identification, not planning. In a planning problem (Chapters 1–2) the path is the answer and costs matter. Here nobody cares in what order you assigned the variables; only the final assignment matters, and all complete assignments sit at the same depth ($n = 4$) of the search tree. That is exactly why CSPs get their own specialised algorithms: since the path is worthless, we can throw away everything except the current partial assignment, and we can spend our effort on filtering (killing doomed branches early) and ordering instead of on path cost.

Why this is the exam version of this idea

Trap 1 — inventing an all-different constraint. Rule 5 explicitly permits sharing. Most students write “all four slots distinct” out of habit, which changes the answer set completely (and would make $A<B<C$ plus distinctness almost deterministic).

Trap 2 — writing $A \le B$ instead of $A < B$. “Finish before it starts” is strict.

Trap 3 — a non-binary formulation. If you index by slot you get constraints over sets and you cannot run AC-3 as taught. When a formulation question is followed by a filtering question, the formulation is being steered toward binary; take the hint.

Definition — arc consistency

An arc $X \to Y$ is consistent iff for every value $x \in D_X$ there exists some $y \in D_Y$ such that $(x,y)$ satisfies the constraint. To enforce it, delete from $D_X$ — the tail — every $x$ with no such partner.

Why this is the exam version of this idea

Trap 1 — deleting from the head. “Remember: delete from the tail!” Enforcing $A \to B$ removes values from $D_A$, not from $D_B$. Half of all AC-3 errors are this one, and they show up as suspiciously symmetric final domains.

Trap 2 — forgetting to re-enqueue. The second pass of $A \to B$ is what shrinks $A$ from $\{1,2,3\}$ to $\{1,2\}$. If you process each arc once and stop, you report $D_A = \{1,2,3\}$ and your answer is not arc consistent. Re-enqueue every arc pointing into the variable you just shrank.

Trap 3 — “AC-3 solved it”. It didn't. Eight solutions remain, and a differently-worded CSP could have zero remaining while every domain is non-empty. Arc consistency is necessary, never sufficient.

Trap 4 — comparing AC-3 with forward checking. Problem 11 needed four assignments to detect failure; AC-3 propagates through chains of unassigned variables and so detects failures earlier — at the cost of doing much more work per node. That trade-off ("what's the downside of enforcing arc consistency?") is a standard short-answer question. Answer: time. AC-3 costs $O(n^2 d^3)$ per run and the backtracking search runs it at every node.

Step 1 — What are we actually being asked?

Still just $\hat R(h) = \frac1N\sum_i \ell(h(x^{(i)}), y^{(i)})$ — but now $\ell$ is a table, read as "row = what we guessed, column = the truth". Two of the four cells are zero, so the sum only has two live terms:

$$\hat R(h) \;=\; \frac{1}{N}\Big[\,\underbrace{\#\text{FN}}_{\hat y=0,\,y=1}\cdot 10 \;+\; \underbrace{\#\text{FP}}_{\hat y=1,\,y=0}\cdot 1 \,\Big].$$

Zero-one loss is the special case where both off-diagonal cells are 1, so $\hat R_{0/1} = (\#\text{FN} + \#\text{FP})/N$ — the error rate, and $1 - \hat R_{0/1}$ is the accuracy.

Part (d) is a different kind of question: not "evaluate a classifier" but "given a probability, what is the cost-minimising decision?" Compare two expected losses and find where they cross.

Step 2 — (a) zero-one loss

$h_1$: errors $= \text{FN} + \text{FP} = 2 + 1 = 3$. $\ \hat R_{0/1} = 3/20 = 0.15$, accuracy $85\%$.

$h_2$: errors $= 0 + 5 = 5$. $\ \hat R_{0/1} = 5/20 = 0.25$, accuracy $75\%$.

By accuracy, $h_1$ is clearly the better model — ten percentage points better.

Step 3 — (b) the hospital's loss

$h_1$: $\ \hat R = \dfrac{2 \cdot 10 + 1 \cdot 1}{20} = \dfrac{20 + 1}{20} = \dfrac{21}{20} = \mathbf{1.05}$.

$h_2$: $\ \hat R = \dfrac{0 \cdot 10 + 5 \cdot 1}{20} = \dfrac{5}{20} = \dfrac{1}{4} = \mathbf{0.25}$.

$h_2$ costs the hospital about one quarter of what $h_1$ costs. The ranking has reversed, and not narrowly — by a factor of four.

Sanity check on the units: $h_1$'s risk exceeds 1, which is fine. The risk is an average cost measured in confirmatory-test units, and a single missed case costs ten of those, so averages above 1 are entirely possible. Only zero-one risk is forced into $[0,1]$.

Step 4 — (d) the decision threshold

Suppose the model tells you $P(y=1 \mid x) = p$. You have two actions.

Flag ($\hat y = 1$): expected loss $= p \cdot \ell(1,1) + (1-p)\cdot \ell(1,0) = p\cdot 0 + (1-p)\cdot 1 = 1 - p$.

Clear ($\hat y = 0$): expected loss $= p \cdot \ell(0,1) + (1-p)\cdot \ell(0,0) = p \cdot 10 + 0 = 10p$.

Flag when flagging is cheaper:

$$1 - p < 10p \iff 1 < 11p \iff p > \frac{1}{11} \approx 0.0909.$$

So flag any patient with more than a $9.1\%$ chance of disease — nowhere near the default threshold of $0.5$. In general, with false-negative cost $c_{\text{FN}}$ and false-positive cost $c_{\text{FP}}$, the break-even point is

$$p^{*} = \frac{c_{\text{FP}}}{c_{\text{FP}} + c_{\text{FN}}},$$

which gives $1/(1+10) = 1/11$ here, and $1/2$ exactly when the two costs are equal — which is the only reason $0.5$ is ever the right threshold.

Why this is the exam version of this idea

The trap is reading accuracy as a measure of quality. Accuracy is $\hat R$ under one specific loss — the one that says every mistake costs the same — and that loss is almost never the one the application has. The exam builds the numbers so that the higher-accuracy model is the worse model, because if you have internalised $\hat R_\ell$ you cannot get this wrong, and if you have memorised "accuracy good" you cannot get it right.

Second trap — transposing the table. Rows are predictions, columns are truth. Write the words "false negative" and "false positive" into the cells before you multiply anything.

Third trap — the threshold of $0.5$. $0.5$ is not a principled threshold; it is the break-even point of a symmetric loss. With a $10{:}1$ cost ratio it moves to $1/11$. Any screening, fraud or safety question is asking you to notice this.

Fourth trap — class imbalance. Here 8 of 20 are positive. Push that to 1 in 1000 and the constant classifier "nobody is ill" scores $99.9\%$ accuracy with risk $10 \cdot 1/1000 = 0.01$ under this table, while catching nothing. Always compute what the trivial classifier scores before claiming a number is good.

Problem 19Axis-aligned decision boundaries exam level

Eight points in $\mathbb{R}^2$ with real-valued features $x_1, x_2$:

$y = 1$  (● teal)$(1,1)$$(2,2)$$(4,4)$$(5,5)$
$y = 0$  (✕ rose)$(1,5)$$(2,4)$$(4,2)$$(5,1)$
The eight points, with the two threshold tests $x_1 = 3$ and $x_2 = 3$ drawn
What to notice: the two drawn tests cut the plane into four quadrants, and each quadrant contains exactly two points of one class. The positives sit in the bottom-left and top-right; the negatives in the top-left and bottom-right. No single straight line of any slope can separate them.
  1. (a) What is the training error of the best single threshold test (a depth-1 stump) on this data?
  2. (b) Write a decision tree with zero training error. What is its depth, and how many leaves does it have?
  3. (c) Can a single linear boundary $\theta_0 + \theta_1 x_1 + \theta_2 x_2 = 0$ achieve zero training error here? Justify it.
  4. (d) Now suppose instead the true rule is $y = 1 \iff x_1 + x_2 \ge 6$. Can a decision tree with axis-aligned threshold tests represent this boundary exactly? What happens as you add depth?
Step 1 — What are we actually being asked?

A decision tree with real-valued features asks tests of the form “is $x_j \le t$?”. Each such test is a single axis-aligned cut — a line perpendicular to one coordinate axis — so every region a tree can carve out is a box (an axis-aligned rectangle, possibly unbounded), and the decision boundary is always a union of horizontal and vertical segments.

That is the entire content of this problem. Parts (a)–(c) ask what that buys you on this dataset; part (d) asks what it costs you on a boundary that isn't axis-aligned.

Do not assume the drawn tests $x_1 = 3$, $x_2 = 3$ are the only candidates. For (a) you must argue about all single tests.

Step 2 — (a) the best stump

Take any vertical cut $x_1 \le t$. Scan the possible $t$: the points' $x_1$ values are $1,1,2,2,4,4,5,5$, and at every $x_1$ value there is exactly one positive and one negative. So whatever $t$ you choose, each side receives equal numbers of each class — a side holding $k$ points holds $k/2$ of each. Majority vote in a tied leaf is wrong half the time, so the error is $\frac12$.

By the symmetry of the data under swapping $x_1 \leftrightarrow x_2$, the same holds for every horizontal cut.

$$\text{error of the best depth-1 stump} = \tfrac{4}{8} = \mathbf{0.5}$$

Which is exactly the error of not splitting at all ($4$ positives, $4$ negatives, so a single leaf is wrong 4 times). No single test helps at all — and the information gain of every single test is $0$ bits for the same reason.

Step 3 — (b) a perfect tree

Split on $x_1 \le 3$, then on $x_2 \le 3$ in both children:

if x1 <= 3:
    if x2 <= 3:  predict 1     # (1,1), (2,2)
    else:        predict 0     # (1,5), (2,4)
else:
    if x2 <= 3:  predict 0     # (4,2), (5,1)
    else:        predict 1     # (4,4), (5,5)

Every leaf is pure, so training error is $\mathbf{0}$. Depth 2, four leaves.

Any threshold strictly between 2 and 4 works for both cuts, so $x_1 \le 3$ and $x_2 \le 3$ are representative rather than special. And note that $x_2$ is tested again below a node — reusing an attribute is required once thresholds are in play, which is why the greedy algorithm does not delete the chosen attribute from $A$ in its recursive call.

The sting: the first split, $x_1 \le 3$, has zero training error reduction and zero information gain. A greedy algorithm scoring one split at a time has no reason to prefer it over any other, yet it is the first half of a perfect tree. This is exactly what "greedy is suboptimal, but it buys computational efficiency" means in practice.

Step 4 — (c) and (d) linear versus axis-aligned

(c) No. This is XOR. Suppose some line gave zero error. Then the signed value $g(x) = \theta_0 + \theta_1x_1 + \theta_2x_2$ would be positive at $(1,1)$ and $(5,5)$ and negative at $(1,5)$ and $(5,1)$. Add up:

$$g(1,1) + g(5,5) = 2\theta_0 + 6\theta_1 + 6\theta_2, \qquad g(1,5) + g(5,1) = 2\theta_0 + 6\theta_1 + 6\theta_2.$$

The two sums are identical — both pairs have the same midpoint $(3,3)$. But the first must be $> 0$ (sum of two positives) and the second $< 0$ (sum of two negatives). Contradiction, so no such line exists. A depth-2 axis-aligned tree solves what no linear model can.

(d) No — not exactly, ever. The boundary $x_1 + x_2 = 6$ is a diagonal line. A tree's boundary is a union of axis-parallel segments, so it can only approximate a diagonal with a staircase. Adding depth adds steps: each extra level halves the step width, so the error region shrinks toward zero but never reaches it. With a finite tree you always misclassify some sliver next to the diagonal.

Two honest footnotes. On a finite training set you can of course reach zero training error — in the worst case with one leaf per point. The impossibility is about representing the boundary over all of $\mathbb{R}^2$, which is what controls test error. And the fix is the one from Section 9: engineer the feature $x_3 = x_1 + x_2$ and a single test $x_3 \ge 6$ is exact. Axis-aligned is a property of the tree in the coordinates you give it.

Solution

(a) $4/8 = 0.5$ — no single threshold test on either feature does better than a single leaf, and every one has zero information gain.

(b) Split $x_1 \le 3$, then $x_2 \le 3$ on both branches: depth 2, 4 leaves, all pure, training error 0.

(c) No. $(1,1),(5,5)$ and $(1,5),(5,1)$ share the midpoint $(3,3)$, so any linear function has the same sum on both pairs; one pair needs a positive sum and the other a negative one.

(d) No. Axis-aligned tests give a staircase boundary; a diagonal needs infinitely many steps. Depth buys a finer staircase and a monotonically smaller error, never an exact fit — unless you add the feature $x_1 + x_2$.

Key idea

Trees and linear models fail on different datasets. Trees shrug off XOR and struggle with diagonals; linear models shrug off diagonals and cannot do XOR at all. "Which model class?" is a question about the shape of the boundary, and the honest answer usually starts with "what do the features look like?".

Why this is the exam version of this idea

Trap 1 — answering (a) from the figure. The drawn lines are at $3$ and $3$, so it is tempting to evaluate only those. The question says "the best single threshold test", which requires an argument over all thresholds on both features. The argument here is a symmetry argument and takes one sentence; a case-by-case scan of nine thresholds takes a page and earns the same marks.

Trap 2 — "greedy would find the depth-2 tree". It might, by tie-breaking, but nothing in the criterion points at it: every first split scores zero on both training error and information gain. This dataset is the standard counterexample to "greedy top-down induction finds the optimal tree".

Trap 3 — confusing "cannot represent" with "cannot fit the training set". In (d), a deep enough tree gets zero training error on any finite sample with no contradictory labels. The claim being tested is about the boundary over the whole input space.

Trap 4 — forgetting that you may re-test a feature. In (b), $x_2$ is tested in both subtrees. Students who learned "remove the attribute from $A$" from the binary-attribute version of the algorithm conclude that no depth-2 tree exists here.

Step 1 — What are we actually being asked?

One parameter, one convex parabola in that parameter, so the minimum is wherever the derivative vanishes. "Derive it" means: write $J(w)$, differentiate with respect to $w$, set to zero, solve. The two sums $\sum x^{(i)}y^{(i)}$ and $\sum (x^{(i)})^2$ will appear by themselves — that is the point of the exercise, and once you have seen them appear you will never again mis-remember which one is on top.

Part (d) is the actual exam content: it offers a plausible-sounding alternative and asks you to show, numerically, that it is worse. "Show it is worse" means compute both objective values.

Step 2 — (a) the derivation
$$J(w) = \frac{1}{N}\sum_{i}\big(wx^{(i)} - y^{(i)}\big)^2$$

Step 1 — What are we actually being asked?

Three different questions wearing one coat.

  • Mechanical: compute a determinant and watch it vanish.
  • Conceptual: "not invertible" and "no solution" are different claims. A convex function with a flat valley floor has infinitely many minimisers and no unique one. Distinguish the minimum value (always exists and is unique) from the minimiser (may not be unique).

Keep the shapes straight: $X \in \mathbb{R}^{3\times2}$, $X^{\top}X \in \mathbb{R}^{2\times2}$.

Step 2 — (a) the determinant
$$X = \begin{pmatrix} 1 & 2 \\ 2 & 4 \\ 3 & 6\end{pmatrix}, \qquad X^{\top}X = \begin{pmatrix} \sum x_1^2 & \sum x_1x_2 \\ \sum x_1 x_2 & \sum x_2^2 \end{pmatrix}$$ $$\sum x_1^2 = 1 + 4 + 9 = 14, \quad \sum x_1x_2 = 2 + 8 + 18 = 28, \quad \sum x_2^2 = 4 + 16 + 36 = 56$$ $$X^{\top}X = \begin{pmatrix} 14 & 28 \\ 28 & 56\end{pmatrix}, \qquad \det = 14 \cdot 56 - 28 \cdot 28 = 784 - 784 = \mathbf{0}$$

No inverse. Notice the structure: the second column of $X^{\top}X$ is exactly twice the first, inherited from $x_2 = 2x_1$. Also, for later, $X^{\top}y = (1\cdot2 + 2\cdot4 + 3\cdot6,\; 2\cdot2+4\cdot4+6\cdot6)^{\top} = (28, 56)^{\top}$ — itself a multiple of the same direction.

Step 3 — (b) all the minimisers

$$h(x^{(i)}) = \theta_1 x_1^{(i)} + \theta_2 x_2^{(i)} = \theta_1 x_1^{(i)} + 2\theta_2 x_1^{(i)} = (\theta_1 + 2\theta_2)\,x_1^{(i)}$$

So the model cannot tell $\theta$ apart from $\theta' $ whenever $\theta_1 + 2\theta_2 = \theta_1' + 2\theta_2'$. It only ever sees the single number $k = \theta_1 + 2\theta_2$, and the hypothesis is $h(x) = k\,x_1$. Two parameters, one degree of freedom — this is what rank deficiency is.

Now fit $k$: the data is $y^{(i)} = 2x_1^{(i)}$ exactly $(1\!\to\!2,\ 2\!\to\!4,\ 3\!\to\!6)$, so $k = 2$ gives zero residuals, and the minimum empirical risk is $\mathbf{0}$.

$$\text{argmin} = \{(\theta_1, \theta_2) : \theta_1 + 2\theta_2 = 2\}$$

— an entire line in parameter space. For example $(2, 0)$, $(0, 1)$, $(4, -1)$ and $(\tfrac23, \tfrac23)$ all achieve risk exactly 0 (check $(4,-1)$: $4 - 2 = 2$ ✓). So a minimiser certainly exists; what fails is uniqueness, and with it the inversion step, since $(X^{\top}X)^{-1}$ would have had to name one particular point on that line.

Geometrically: $J$ is a convex paraboloid in $(\theta_1, \theta_2)$ that is a parabola in the direction $(1,2)$ and perfectly flat in the direction $(2,-1)$. A flat valley floor, not a bowl, so no unique bottom.

The practical reading: $\theta_1 = 4,\ \theta_2 = -1$ fits the data perfectly and says "area helps a lot, half-area hurts". That sentence is meaningless, and any interpretation of individual weights under collinearity is meaningless in exactly this way.

Step 4 — (c) the general condition

$X^{\top}X$ is invertible $\iff$ $\operatorname{rank}(X) = d$ $\iff$ the columns of $X$ are linearly independent.

Here $\operatorname{rank}(X) = 1$: the two columns are parallel, so one direction in feature space is simply absent from the data. $N = 3 \ge d = 2$ is necessary but nowhere near sufficient — $N \ge d$ counts rows, and rank is about columns. The two ways to fail:

  • Exact collinearity (this problem): one feature is a linear combination of the others. Duplicated features, unit conversions, a one-hot encoding that keeps all $k$ categories and an intercept (the dummy-variable trap — the $k$ indicator columns sum to the ones column), or an engineered feature like $x_3 = x_1 + x_2$.
  • $N < d$: fewer examples than parameters. Then $\operatorname{rank}(X) \le N < d$ and $X^{\top}X$ is singular automatically, with a whole subspace of perfect fits. This is the high-dimensional regime, and it is why a degree-12 polynomial fitted to 10 points has no unique solution.

Near-singular is the case you actually meet: $\det$ tiny rather than exactly 0, so the inverse exists but has huge entries, and $\theta^{*}$ swings wildly on a rounding error in $y$. That instability, not the literal failure to invert, is what collinearity costs you in practice.

Step 5 — (d) the ridge fix
$$X^{\top}X + 2I = \begin{pmatrix} 14 + 2 & 28 \\ 28 & 56 + 2\end{pmatrix} = \begin{pmatrix} 16 & 28 \\ 28 & 58\end{pmatrix}$$ $$\det = 16\cdot 58 - 28 \cdot 28 = 928 - 784 = \mathbf{144} \ne 0$$

Invertible. $\ (X^{\top}X + 2I)^{-1} = \dfrac{1}{144}\begin{pmatrix} 58 & -28 \\ -28 & 16\end{pmatrix}$, and with $X^{\top}y = (28,56)^{\top}$:

$$\theta_{\text{ridge}} = \frac{1}{144}\begin{pmatrix}58 & -28\\ -28 & 16\end{pmatrix}\begin{pmatrix}28\\56\end{pmatrix} = \frac{1}{144}\begin{pmatrix} 1624 - 1568 \\ -784 + 896\end{pmatrix} = \frac{1}{144}\begin{pmatrix}56 \\ 112\end{pmatrix} = \begin{pmatrix} 7/18 \\ 7/9 \end{pmatrix}$$

$\theta_{\text{ridge}} \approx (0.389,\ 0.778)$ — a single, unique answer. Three things to read off it:

  • $\theta_1 + 2\theta_2 = \frac{7}{18} + \frac{14}{9} = \frac{7 + 28}{18} = \frac{35}{18} \approx 1.944$, slightly less than the unpenalised $2$. Ridge shrinks: it no longer fits the data perfectly, trading a little risk for a unique, small-norm solution.
  • Of all the points on the line $\theta_1 + 2\theta_2 = k$, ridge picks the one nearest the origin, which is why the collinear pair ends up sharing the weight ($\theta_2 = 2\theta_1$ here) instead of one taking $+4$ and the other $-1$.
  • Adding $\lambda I$ raises every eigenvalue by $\lambda > 0$. Since $X^{\top}X$ is always positive semi-definite, its eigenvalues are $\ge 0$, so they all become $\ge \lambda > 0$ and the matrix is invertible for any dataset at all. This is a guarantee, not a trick that happened to work on these numbers.
Solution

(a) $X^{\top}X = \begin{pmatrix}14&28\\28&56\end{pmatrix}$, $\det = 0$.

(b) Minimisers exist but are not unique: every $\theta$ with $\theta_1 + 2\theta_2 = 2$ attains the minimum empirical risk of $0$ — a line in parameter space, e.g. $(2,0)$, $(0,1)$, $(4,-1)$.

(c) Because $\operatorname{rank}(X) = 1 < d = 2$: the columns are linearly dependent ($x_2 = 2x_1$). The condition is that $X^{\top}X$ is invertible iff the columns of $X$ are linearly independent; $N \ge d$ is necessary, not sufficient.

(d) $X^{\top}X + 2I = \begin{pmatrix}16&28\\28&58\end{pmatrix}$ with $\det = 144$, giving the unique $\theta_{\text{ridge}} = (7/18,\ 7/9)^{\top} \approx (0.389, 0.778)$.

Why this is the exam version of this idea

Trap 1 — "singular means no solution". It means no unique solution. The empirical risk here is minimised exactly, at infinitely many places. Writing "the problem is infeasible" loses the marks; writing "the minimiser is not unique; the set of minimisers is the line $\theta_1 + 2\theta_2 = 2$" gets all of them.

Trap 2 — "just add more data". Does nothing. Every new row obeys $x_2 = 2x_1$ too, so rank stays 1 no matter how many rows you have. Collinearity is a property of the feature definitions, and the fixes are to drop a feature, combine them, or regularize.

Trap 3 — $N \ge d$ as the invertibility test. It is the condition people remember and it is not the condition. Here $N > d$ and the matrix is still singular. Rank is about columns.

Trap 4 — interpreting weights under collinearity. $(4, -1)$ and $(0,1)$ are equally optimal and tell opposite stories about whether area matters. If two features are nearly collinear, the sign of either weight is noise; that is the honest thing to say about it.

The sign of $\rho$ tells you the shape of the trajectory and $|\rho|$ tells you whether it converges. $0 < \rho < 1$: approach from one side. $\rho = 0$: one step. $-1 < \rho < 0$: converge while alternating sides. $|\rho| \ge 1$: never converges. Trap 4 — expecting to reach $w^{*}$ exactly. At $\alpha = \tfrac18$ the iterates are $8, 4, 2, 1, \tfrac12, \dots$ — they halve forever and never equal 0. Step 4 — (d) and (e)

(d) $2A\theta = 2\begin{pmatrix}10\\6\end{pmatrix} = \begin{pmatrix}20\\12\end{pmatrix}$ — not $(12, 16)^{\top}$. Both components are wrong, and the first is wrong by a lot.

$2A\theta$ is correct exactly when $A = A^{\top}$, because then $A + A^{\top} = 2A$. Our $A$ has $A_{12} = 4$ and $A_{21} = 0$, so it is not symmetric and the shortcut fails. It is a safe shortcut in the one place it is used most — $X^{\top}X$ in the normal equations is symmetric by construction, giving $\nabla_\theta(\theta^{\top}X^{\top}X\theta) = 2X^{\top}X\theta$ — and that is precisely why people reach for it when it does not apply.

(e) One step with $\alpha = \tfrac14$:

$$\theta^{(1)} = \theta - \alpha\nabla_\theta J = \begin{pmatrix}1\\2\end{pmatrix} - \tfrac14\begin{pmatrix}12\\16\end{pmatrix} = \begin{pmatrix}1 - 3\\ 2 - 4\end{pmatrix} = \begin{pmatrix}\mathbf{-2}\\ \mathbf{-2}\end{pmatrix}$$

Both coordinates update simultaneously, from the same old $\theta$. Do not feed the new $\theta_1$ into the computation of $\theta_2$ — that is a different algorithm (coordinate descent).

Worth noticing: $J(-2,-2) = 2(4) + 4(4) + 3(4) = 8 + 16 + 12 = 36 > 22$. The step made things worse, because $\alpha = \tfrac14$ is too large here and because this $J$ is not even bounded below — $A$'s symmetric part $\begin{pmatrix}2&2\\2&3\end{pmatrix}$ happens to be positive definite ($\det = 2 > 0$, trace $> 0$), so $J \ge 0$ with its minimum at the origin, and $\theta = (-2,-2)$ overshot straight past it. A step can increase the objective; that is information about $\alpha$, not a mistake in the gradient.

Solution

(a) $J(\theta) = 22$.   (b) $\nabla_\theta J = (A+A^{\top})\theta = \begin{pmatrix}4&4\\4&6\end{pmatrix}\begin{pmatrix}1\\2\end{pmatrix} = (12, 16)^{\top}$.

(c) $J = 2\theta_1^2 + 4\theta_1\theta_2 + 3\theta_2^2$, so $\partial J/\partial\theta_1 = 4\theta_1 + 4\theta_2 = 12$ and $\partial J/\partial\theta_2 = 4\theta_1 + 6\theta_2 = 16$ ✓.

(d) $2A\theta = (20, 12)^{\top}$, which is wrong. It is valid only for symmetric $A$.

(e) $\theta^{(1)} = (-2, -2)^{\top}$, at which $J = 36$ — an increase, because $\alpha = \tfrac14$ overshoots.

Why this is the exam version of this idea

The trap is the non-symmetric $A$. Every quadratic form you meet in linear regression is built from $X^{\top}X$, which is symmetric, so $2A\theta$ works every time you have practised it. The exam hands you an $A$ with a zero in one off-diagonal slot, which is a deliberate flag: $A_{12} \ne A_{21}$ means you must use $A + A^{\top}$.

Second trap — transposing wrongly, or forgetting the $\theta$. $A + A^{\top}$ is a matrix, not the gradient. The gradient is that matrix times $\theta$. Reporting $\begin{pmatrix}4&4\\4&6\end{pmatrix}$ as "the gradient" is a shape error.

Third trap — updating coordinates sequentially. Gradient descent evaluates the whole gradient at $\theta^{(t-1)}$ and then moves. Using the freshly-updated $\theta_1$ when computing $\theta_2$ gives $(-2, -3)$ here, which is Gauss–Seidel-style coordinate descent, not gradient descent.

Fourth trap — assuming $J$ must decrease. Descent is only guaranteed for small enough $\alpha$. Seeing $J$ rise from 22 to 36 is the diagnostic from Problem 23 appearing in two dimensions.

Step 5 — (e) the cost accounting, and the real tradeoff

One per-example gradient $(\hat y^{(i)} - y^{(i)})\,x^{(i)}$ costs $O(d)$ — here about $50$ multiply-adds. A batch gradient averages $N$ of them: $O(Nd) = 10^6 \times 50 = 5\times10^{7}$ operations per single update to $\theta$.

$$\frac{\text{cost of one batch step}}{\text{cost of one SGD step}} = \frac{Nd}{d} = N = \mathbf{10^6}$$

So in the time batch takes to move $\theta$ once, SGD moves it a million times. Even if each of those steps is in a mildly wrong direction, a million mediocre steps beat one perfect one by a wide margin, and that — not any statistical subtlety — is why large-scale learning uses SGD.

(e) $Nd/d = N = 10^6$ SGD updates per batch update. Batch gives exact directions at $O(Nd)$ per step; SGD gives noisy directions at $O(d)$ per step and wins on wall-clock whenever $N$ is large, at the price of needing a smaller, usually decaying $\alpha$.

Why this is the exam version of this idea

Trap 1 — the missing $\frac1N$. $J$ here is defined with $\frac14$, so the batch gradient carries $\frac{2}{4}$ and comes out as $-9$, not $-36$. Forget it and your batch step is four times too big ($w^{(1)} = 9$), which makes batch look wildly unstable and inverts the entire conclusion. Read the definition of $J$ in the question, every time.

Trap 2 — comparing one batch step to one SGD step. That comparison is rigged, because a batch step costs $N$ times more. Compare per unit of arithmetic: one batch step versus one epoch of $N$ SGD steps — which is exactly what (b) versus (c) does.

Trap 3 — reusing a stale $w$ inside the epoch. SGD updates $w$ after every single example. Computing all four per-example gradients at $w = 0$ and applying them one after another is just a batch step with the wrong scaling; the four gradients at $w=0$ are $-4, 0, -8, -24$, so you would land at $w = 0 + 1 + 0 + 2 + 6 = 9$ — a different algorithm with a very different answer. Recompute the residual from the current $w$ at every step.

Trap 4 — "SGD is worse because $J$ went up". SGD's noise is not purely a cost: on a non-convex objective it can jump out of a poor local minimum, which batch cannot. On a convex objective like this one there is nothing to escape, so the noise is pure cost and smaller steps are pure gain. Say which regime you are in before judging it.

Problem 26Write $\phi$, and give the shape of $\Phi$ warm-up

For each hypothesis below, write the feature transform $\phi$ explicitly as a vector, state $M$ (its output dimension), and give the shape of the transformed design matrix $\Phi$.

  1. (a) One original feature $x \in \mathbb{R}$, $N = 12$ examples, and $$h(x) = \theta_0 + \theta_1 x + \theta_2 x^3 + \theta_3 \sin x.$$
  2. (b) Two original features $x = (x_1, x_2)$, $N = 50$ examples, and the full degree-2 polynomial — every monomial of degree $\le 2$, cross term included.
  3. (c) For (b), write the row of $\Phi$ corresponding to the example $x = (2, 3)$.
  4. (d) For (b), give $\theta^{*}$ in closed form. Is this model linear? Linear in what?
  5. (e) How many features does a full degree-$D$ polynomial in $K = 2$ original features have? Evaluate at $D = 3$.
Step 1 — What are we actually being asked?

$\phi : \mathbb{R}^{K} \to \mathbb{R}^{M}$ takes the $K$ original features of one example and returns the $M$ features you actually regress on. The rule for reading it off a hypothesis is mechanical:

Each $\theta_j$ in the hypothesis multiplies exactly one entry of $\phi(x)$ — so list the things the $\theta$s multiply, in order. A bare $\theta_0$ with nothing attached multiplies the constant $1$, so $\phi$ starts with a $1$; that is where the bias column comes from.

Then $\Phi \in \mathbb{R}^{N \times M}$, with row $i$ equal to $\phi(x^{(i)})^{\top}$ — one row per example, one column per produced feature. $N$ never changes under feature engineering; $M$ does.

Step 2 — (a) and (b)

(a) The four $\theta$s multiply $1$, $x$, $x^3$ and $\sin x$:

$$\phi(x) = \begin{pmatrix} 1 \\ x \\ x^3 \\ \sin x\end{pmatrix} \in \mathbb{R}^{4}, \qquad M = 4, \qquad \Phi \in \mathbb{R}^{12 \times 4}$$

There is no $x^2$ term, so there is no $x^2$ entry. $\phi$ is read off the hypothesis you were given, not off a template for "the degree-3 polynomial".

(b) The monomials in $x_1, x_2$ of total degree $\le 2$ are $1$; $x_1, x_2$; $x_1^2, x_1x_2, x_2^2$:

$$\phi(x_1,x_2) = \begin{pmatrix} 1 \\ x_1 \\ x_2 \\ x_1^2 \\ x_1x_2 \\ x_2^2\end{pmatrix} \in \mathbb{R}^{6}, \qquad M = \mathbf{6}, \qquad \Phi \in \mathbb{R}^{50\times 6}$$ $$h(x) = \theta_0 + \theta_1x_1 + \theta_2x_2 + \theta_3x_1^2 + \theta_4x_1x_2 + \theta_5x_2^2$$

The cross term $x_1x_2$ is the one people drop, and it is the only one that lets the model represent an interaction — the whole reason to go to degree 2 with more than one feature.

Step 3 — (c) and (d)

(c) With $x_1 = 2$, $x_2 = 3$: $\ x_1^2 = 4$, $x_1x_2 = 6$, $x_2^2 = 9$.

$$\phi(2,3)^{\top} = \begin{pmatrix} 1 & 2 & 3 & 4 & 6 & 9\end{pmatrix}$$

Six numbers in one row of $\Phi$, from an example that arrived as two numbers.

(d) Identical to the normal equations with $X$ replaced by $\Phi$:

$$\theta^{*} = (\Phi^{\top}\Phi)^{-1}\Phi^{\top}y, \qquad \Phi^{\top}\Phi \in \mathbb{R}^{6\times6}$$

And yes, the model is still linear — linear in $\theta$, which is the only linearity least squares ever required. $h$ is a curved, quadratic surface in $x$; it is a flat, linear function of the parameters. Every result from Section 7 carries over unchanged: the same closed form, the same convexity, the same singularity condition (now on the columns of $\Phi$).

That last point matters: engineered features collide easily. Add $x_3 = x_1 + x_2$ to $\phi$ and $\Phi$ is instantly rank-deficient, exactly as in Problem 22.

Step 4 — (e) counting

The monomials of degree $\le D$ in $K$ variables number $\binom{D + K}{K}$. With $K = 2$:

$$M = \binom{D+2}{2} = \frac{(D+1)(D+2)}{2}$$

Check at $D = 2$: $\frac{3 \cdot 4}{2} = 6$ ✓ — matches the six entries we listed. At $D = 3$:

$$M = \frac{4 \cdot 5}{2} = \mathbf{10}$$

namely $1$; $x_1, x_2$; $x_1^2, x_1x_2, x_2^2$; $x_1^3, x_1^2x_2, x_1x_2^2, x_2^3$. Count them: $1 + 2 + 3 + 4 = 10$ ✓.

This growth is the whole problem with polynomial features. At $K = 10$ original features, degree 2 already gives $\binom{12}{2} = 66$ features and degree 3 gives $\binom{13}{3} = 286$. More features means a richer hypothesis class, which means a better training fit and, past some point, worse generalization — which is Problem 27.

Solution

(a) $\phi(x) = (1,\ x,\ x^3,\ \sin x)^{\top}$, $M = 4$, $\Phi \in \mathbb{R}^{12\times4}$.

(b) $\phi(x) = (1,\ x_1,\ x_2,\ x_1^2,\ x_1x_2,\ x_2^2)^{\top}$, $M = 6$, $\Phi \in \mathbb{R}^{50\times6}$.

(c) $(1,\ 2,\ 3,\ 4,\ 6,\ 9)$.

(d) $\theta^{*} = (\Phi^{\top}\Phi)^{-1}\Phi^{\top}y$. The model is linear in $\theta$ (not in $x$), which is all least squares needs.

(e) $\binom{D+2}{2} = \frac{(D+1)(D+2)}{2}$; at $D=3$ that is $10$.

Why this is the exam version of this idea

Trap 1 — dropping the leading 1. Then $M = 3$ in (a) and the model is forced through the origin. The bias is a feature that is constantly 1; it has to be in $\phi$ or there is nothing for $\theta_0$ to multiply.

Trap 2 — dropping the cross term. "Degree 2 in two variables" is six terms, not five and not four. If the question says "full" or "including interactions", the cross term is being checked explicitly.

Trap 3 — writing $\Phi \in \mathbb{R}^{M \times N}$. Rows are examples. $\Phi$ is tall and thin when $N > M$, which is the regime you want. Get this backwards and every subsequent matrix product is ill-shaped.

Trap 4 — "this is nonlinear regression". It is linear regression on nonlinear features. The distinction is not pedantry: it is exactly why you still get a closed form and a convex objective, and it is a one-line short-answer question that appears on these exams verbatim.

Trap 4 — picking by training error. $D$ wins on training error and loses on everything else. Any question of the form "which model would you deploy" is checking whether you look at the held-out column.

Problem 28Sigmoid, cross-entropy and one gradient step, by hand exam level

Binary logistic regression with $\sigma(z) = \dfrac{1}{1 + e^{-z}}$, prediction $h_\theta(x) = \sigma(\theta^{\top}x)$, and average cross-entropy loss

$$J(\theta) = -\frac{1}{N}\sum_{i=1}^{N}\Big[y^{(i)}\ln h_\theta(x^{(i)}) + \big(1-y^{(i)}\big)\ln\big(1 - h_\theta(x^{(i)})\big)\Big], \qquad \nabla_\theta J = \frac{1}{N}\sum_{i=1}^{N}\big(h_\theta(x^{(i)}) - y^{(i)}\big)x^{(i)}.$$

Current parameters and two training examples (the leading 1 in each $x$ is the bias feature):

$$\theta = \begin{pmatrix}0 \\ 1 \\ -1\end{pmatrix}, \qquad x^{(1)} = \begin{pmatrix}1\\2\\1\end{pmatrix},\ y^{(1)} = 1, \qquad x^{(2)} = \begin{pmatrix}1\\1\\2\end{pmatrix},\ y^{(2)} = 0.$$

Given, so no calculator is needed: $\sigma(1) = 0.731$, $\sigma(-1) = 0.269$, $\sigma(0) = 0.5$, $\ \ln 2 = 0.693$, $\ -\ln(0.731) = 0.313$, $\ -\ln(0.269) = 1.313$. Note $\sigma(-z) = 1 - \sigma(z)$.

  1. (a) Compute $z^{(i)} = \theta^{\top}x^{(i)}$ and $h_\theta(x^{(i)})$ for both examples.
  2. (b) Compute the per-example cross-entropy losses and $J(\theta)$.
  3. (c) Compute $\nabla_\theta J$.
  4. (d) Take one gradient step with $\alpha = 1$. Report $\theta^{(1)}$, the new $z$ values, and say whether $J$ went up or down — with a reason, not a calculation.
  5. (e) At $\theta$, what are the predicted labels at threshold $0.5$, and what are the odds that example 1 is positive?
The sigmoid, with the two examples' scores marked
What to notice: the two examples land symmetrically about $z = 0$, at $+1$ and $-1$, so their predicted probabilities $0.731$ and $0.269$ sum to exactly 1 — the symmetry $\sigma(-z) = 1 - \sigma(z)$ read straight off the curve. Because $y^{(1)} = 1$ and $y^{(2)} = 0$, both examples are on the correct side of the dashed threshold, and both incur the same loss.
Step 1 — What are we actually being asked?

Three stages, strictly in order, because each feeds the next: a score $z = \theta^{\top}x$ (any real number), a probability $h = \sigma(z) \in (0,1)$, and a loss built from that probability. Then one gradient step.

The gradient formula is given, and it is worth staring at: $\nabla_\theta J = \frac1N\sum_i (h^{(i)} - y^{(i)})x^{(i)}$. The bracket is the residual — predicted probability minus actual label — and it is exactly the same shape as linear regression's gradient. No $\sigma'$ appears anywhere, because the derivative of the sigmoid and the derivative of the logarithm cancel. That cancellation is the reason cross-entropy is the loss of choice here.

Shapes: $z$ is a scalar per example, $h$ is a scalar per example, $\nabla_\theta J \in \mathbb{R}^3$ — same shape as $\theta$, because each term is a scalar times $x^{(i)} \in \mathbb{R}^3$.

Step 2 — (a) scores and probabilities
$$z^{(1)} = \theta^{\top}x^{(1)} = (0)(1) + (1)(2) + (-1)(1) = 0 + 2 - 1 = \mathbf{1}$$ $$z^{(2)} = \theta^{\top}x^{(2)} = (0)(1) + (1)(1) + (-1)(2) = 0 + 1 - 2 = \mathbf{-1}$$ $$h^{(1)} = \sigma(1) = \mathbf{0.731}, \qquad h^{(2)} = \sigma(-1) = \mathbf{0.269}$$

Consistency check: $0.731 + 0.269 = 1.000$ ✓, as $\sigma(-z) = 1 - \sigma(z)$ demands.

Step 3 — (b) the losses

Only one of the two terms survives per example, because $y$ is 0 or 1.

Example 1, $y = 1$: the loss is $-\ln h$:

$$\ell^{(1)} = -\ln(0.731) = \mathbf{0.313}$$

Example 2, $y = 0$: the loss is $-\ln(1 - h)$, and $1 - 0.269 = 0.731$:

$$\ell^{(2)} = -\ln(1 - 0.269) = -\ln(0.731) = \mathbf{0.313}$$ $$J(\theta) = \frac{0.313 + 0.313}{2} = \mathbf{0.313}$$

Both examples cost the same, which the figure explains: each is the same distance on the correct side of the boundary. For scale, a model that said $0.5$ for everything would score $-\ln(0.5) = \ln 2 = 0.693$, so $0.313$ is genuinely better than knowing nothing — a comparison always worth making, since cross-entropy has no natural units.

Note which probability goes inside the log: for $y = 0$ it is $1 - h$, the probability the model assigns to the true class. In both cases the loss is $-\ln P(\text{correct class})$, which is the whole content of cross-entropy and much easier to remember than the two-term formula.

Step 4 — (c) the gradient

Residuals first:

$$h^{(1)} - y^{(1)} = 0.731 - 1 = -0.269, \qquad h^{(2)} - y^{(2)} = 0.269 - 0 = +0.269$$

Equal and opposite — again the symmetry. Now weight each $x^{(i)}$ by its residual and average:

$$\nabla_\theta J = \frac12\left[(-0.269)\begin{pmatrix}1\\2\\1\end{pmatrix} + (0.269)\begin{pmatrix}1\\1\\2\end{pmatrix}\right] = \frac{0.269}{2}\left[\begin{pmatrix}-1\\-2\\-1\end{pmatrix} + \begin{pmatrix}1\\1\\2\end{pmatrix}\right] = \frac{0.269}{2}\begin{pmatrix}0\\-1\\1\end{pmatrix}$$ $$\nabla_\theta J = \begin{pmatrix}\mathbf{0} \\ \mathbf{-0.1345} \\ \mathbf{+0.1345}\end{pmatrix}$$

The bias component is exactly zero, and that is not a coincidence: the bias feature is $1$ for every example, so its gradient component is the plain average of the residuals, $\frac12(-0.269 + 0.269) = 0$. One example is under-predicted by as much as the other is over-predicted, so there is no pressure to shift the whole boundary — only to rotate it.

Step 5 — (d) and (e)

(d) With $\alpha = 1$:

$$\theta^{(1)} = \theta - 1\cdot\nabla_\theta J = \begin{pmatrix}0\\1\\-1\end{pmatrix} - \begin{pmatrix}0\\-0.1345\\0.1345\end{pmatrix} = \begin{pmatrix}\mathbf{0}\\ \mathbf{1.1345}\\ \mathbf{-1.1345}\end{pmatrix}$$ $$z^{(1)}_{\text{new}} = 0 + 2(1.1345) - 1.1345 = \mathbf{+1.1345}, \qquad z^{(2)}_{\text{new}} = 0 + 1.1345 - 2(1.1345) = \mathbf{-1.1345}$$

$J$ went down, and you can say so without evaluating a single logarithm. Example 1 is a positive whose score rose from $1$ to $1.1345$, so $h^{(1)}$ rose and $-\ln h^{(1)}$ fell. Example 2 is a negative whose score fell from $-1$ to $-1.1345$, so $h^{(2)}$ fell and $-\ln(1-h^{(2)})$ fell too. Both terms decreased, so the average decreased. (For the record: $J$ goes from $0.313262$ to $0.278837$.)

Each example moved further onto its own correct side. That is what the gradient step did: it steepened the boundary rather than moving it, exactly as the zero bias component predicted.

(e) Threshold $0.5$ on $h$ is the same as threshold $0$ on $z$, since $\sigma$ is increasing and $\sigma(0) = 0.5$. So:

  • Example 1: $h = 0.731 > 0.5 \Rightarrow \hat y = 1$, and $y = 1$ ✓ correct.
  • Example 2: $h = 0.269 < 0.5 \Rightarrow \hat y = 0$, and $y = 0$ ✓ correct.

Both correct — zero-one loss is $0/2 = 0$ — while cross-entropy is still $0.313$. Cross-entropy keeps pushing after the classification is already right, because it scores confidence, not correctness; that is precisely why it is differentiable and usable, and why zero-one loss is not.

Odds. Logistic regression is linear in the log-odds:

$$\ln\frac{h}{1-h} = \theta^{\top}x = z \qquad\Longrightarrow\qquad \frac{h^{(1)}}{1 - h^{(1)}} = e^{z^{(1)}} = e^{1} \approx 2.718$$

Check it directly: $0.731/0.269 = 2.717$, matching $e \approx 2.718$ up to the rounding in the given $\sigma$ values ✓. Example 1 is about $2.7$ times more likely positive than negative.

Why this is the exam version of this idea

Trap 1 — inserting a $\sigma'$ into the gradient. The chain rule looks like it should leave a factor $\sigma(z)(1-\sigma(z))$ behind. It cancels against the $1/h$ from differentiating $\ln h$. Trap 2 — using $h$ instead of $1-h$ for a negative example. For $y = 0$ the loss is $-\ln(1 - h)$. Plugging in $-\ln(0.269) = 1.313$ gives $J = 0.813$ instead of $0.313$, and the number even looks plausible. Say out loud "probability of the true class" before you take the log.

Trap 3 — forgetting the bias feature. $\theta \in \mathbb{R}^3$ and $x \in \mathbb{R}^3$ with a leading 1. Drop it and $z^{(1)} = 1$ by coincidence here, but the gradient loses a component and the shapes stop matching.

Trap 4 — "both examples are classified correctly, so the loss is 0". That is zero-one loss. Cross-entropy is $0.313$ and still has a nonzero gradient, which is the only reason the step in (d) exists. Confusing "correct" with "zero loss" is the single most common conceptual error in this chapter.

Trap 5 — $\ln$ versus $\log_2$. Entropy problems in Section 6 used $\log_2$; cross-entropy here uses $\ln$. The two differ by a factor $\ln 2$, which never changes an $\arg\min$ but always changes the number. Use whichever the question writes.

Problem 29Ridge versus LASSO, and why the bias is exempt exam level

Regularized ERM with a feature transform $\phi$:

$$\theta^{\star} = \arg\min_{\theta}\ \underbrace{\frac1N\sum_{i=1}^{N}\big(\theta^{\top}\phi(x^{(i)}) - y^{(i)}\big)^2}_{\hat R(\theta)} \;+\; \lambda\, r(\theta), \qquad r_{\text{ridge}}(\theta) = \sum_{j\ge1}\theta_j^2, \qquad r_{\text{lasso}}(\theta) = \sum_{j\ge1}|\theta_j|.$$

Two candidate weight vectors (ignore the bias for now) happen to achieve exactly the same empirical risk $\hat R = 0.5$ on the training set:

$$\theta_A = (3,\ 0), \qquad \theta_B = (2,\ 2).$$
  1. (a) Compute both penalties for both vectors, then the full objective under each regularizer with $\lambda = 1$.
  2. (b) Which vector does Ridge choose? Which does LASSO choose? Explain the disagreement in one sentence.
  3. (c) Why does LASSO produce weights that are exactly zero while Ridge merely shrinks?
  4. (d) Why is $\theta_0$ excluded from both sums? Give a concrete consequence of including it.
  5. (e) What happens as $\lambda \to 0$ and as $\lambda \to \infty$? And why must features be standardized first?
Step 1 — What are we actually being asked?

The objective is a sum of two competing terms: fit, which wants large weights that chase the data, and penalty, which wants small weights. $\lambda$ sets the exchange rate between them.

This problem rigs $\hat R$ to be identical for the two candidates, so the fit term cancels out of the comparison and you are looking at the penalty alone. That is artificial on purpose: it isolates the question "what shape of solution does each penalty prefer, all else equal?", which is the thing you are actually being tested on.

Then parts (c)–(e) are short-answer, and each has a specific right answer, not a vibe.

Step 2 — (a) the four penalties
$\sum_j \theta_j^2$ (Ridge)$\sum_j|\theta_j|$ (LASSO)
$\theta_A = (3,0)$$9 + 0 = 9$$3 + 0 = \mathbf{3}$
$\theta_B = (2,2)$$4 + 4 = \mathbf{8}$$2 + 2 = 4$

Full objectives with $\hat R = 0.5$ and $\lambda = 1$:

Ridge objectiveLASSO objective
$\theta_A = (3,0)$$0.5 + 9 = 9.5$$0.5 + 3 = \mathbf{3.5}$ ✓
$\theta_B = (2,2)$$0.5 + 8 = \mathbf{8.5}$ ✓$0.5 + 4 = 4.5$

Note that both vectors have the same total "size" in a loose sense — $3 + 0$ versus $2+2$ is only off by one — yet squaring swings the comparison the other way, because $3^2 = 9$ punishes concentration while $2^2 + 2^2 = 8$ rewards spreading.

Step 3 — (b) and (c)

(b) Ridge chooses $\theta_B = (2,2)$; LASSO chooses $\theta_A = (3,0)$.

In one sentence: squaring penalises a single large weight more than two medium ones, so Ridge spreads weight across correlated features; the absolute value prices every unit of weight the same wherever it sits, so what LASSO can save is the number of features used — and LASSO drops one entirely.

(c) Look at how each penalty behaves for one weight near zero, with everything else fixed.

  • Ridge: $\frac{d}{d\theta_j}\lambda\theta_j^2 = 2\lambda\theta_j \to 0$ as $\theta_j \to 0$. The penalty's pull toward zero vanishes right where you would need it most, so any tiny nonzero gradient from the fit term holds $\theta_j$ at a small nonzero value. Shrinkage, never elimination.
  • LASSO: $\frac{d}{d\theta_j}\lambda|\theta_j| = \pm\lambda$, a constant pull of size $\lambda$ that does not vanish near zero. If the fit term's pull on $\theta_j$ is weaker than $\lambda$, the two cannot balance anywhere except exactly at $\theta_j = 0$, where the kink lets the subgradient absorb the difference. Hence exact zeros.

Geometrically: the LASSO constraint region $\sum|\theta_j| \le c$ is a diamond, with corners on the axes, and a corner is where a coordinate is exactly 0. The Ridge region $\sum\theta_j^2 \le c$ is a circle, which touches a generic objective contour at a point with every coordinate nonzero. That is why LASSO performs feature selection and Ridge does not.

Step 4 — (d) the bias exemption

Both sums start at $j = 1$: $\theta_0$ is never penalised. Three reasons, in increasing order of how likely they are to be the expected answer.

1. $\theta_0$ is not a feature weight. Regularization encodes the prior belief "features probably do not matter much, so keep their weights small". The bias is not a feature; it is the model's baseline level, and shrinking it expresses the belief that $y$ is probably near zero — a belief about your units, not about the data.

2. Concrete consequence: you lose shift-equivariance. Suppose every $y^{(i)}$ is in dollars and you switch to cents, multiplying all $y$ by 100 — or simply add 1000 dollars to every house price. The correct response is for $\theta_0$ to grow accordingly, with the feature weights unchanged. A penalty $\lambda\theta_0^2$ fights this: at $\lambda$ large enough, the fitted intercept is dragged toward 0 and every prediction is biased low for the whole dataset, uniformly. Penalising $\theta_0$ makes your model's answers depend on where you happened to put the origin of $y$.

3. At $\lambda \to \infty$ the model should be the best constant, not zero. With the bias exempt, infinite $\lambda$ drives $\theta_{1..M} \to 0$ and leaves $\theta_0 = \bar y$, i.e. "always predict the training mean" — the sensible maximally-underfit model. With the bias penalised, infinite $\lambda$ gives $h \equiv 0$, which is not a model of anything.

Step 5 — (e) the two limits, and standardization

$\lambda \to 0$: the penalty disappears and you recover ordinary least squares, $\theta^{\star} \to (\Phi^{\top}\Phi)^{-1}\Phi^{\top}y$. Maximum variance, minimum bias — and if $\Phi^{\top}\Phi$ is singular (Problem 22), no unique answer at all.

$\lambda \to \infty$: all penalised weights are crushed to 0 and the prediction becomes the constant $\theta_0 = \bar y$. Maximum bias, zero variance — guaranteed underfitting. Between the extremes, training error increases monotonically with $\lambda$ while test error is U-shaped, which is why $\lambda$ is chosen on held-out data (Problem 30) and never on the training set — on the training set the answer is always $\lambda = 0$.

Standardization. Both penalties are stated in the units of the weights, and a weight's units are the inverse of its feature's. Measure a distance feature in kilometres instead of metres and its values shrink by 1000, so the fitted weight must grow by 1000 to make the same prediction — and its Ridge penalty grows by $10^6$. The same model, the same data, a thousand-fold different penalty, purely because of a unit choice. So subtract the mean and divide by the standard deviation of each feature first (using the training statistics, applied unchanged to test data); then one unit of weight means the same thing in every coordinate and $\lambda$ is a meaningful single knob.

Solution

(a) Ridge: $9$ for $\theta_A$, $8$ for $\theta_B$ (objectives $9.5$ and $8.5$). LASSO: $3$ for $\theta_A$, $4$ for $\theta_B$ (objectives $3.5$ and $4.5$).

(b) Ridge picks $\theta_B = (2,2)$; LASSO picks $\theta_A = (3,0)$. Squaring penalises one big weight more than two medium ones, so Ridge spreads; the absolute value prices weight uniformly, so LASSO zeroes a coordinate out.

(c) LASSO's derivative is $\pm\lambda$ and does not vanish at $0$, so a weight whose fit-gradient is smaller than $\lambda$ can only balance exactly at zero (the diamond's corners lie on the axes). Ridge's derivative $2\lambda\theta_j \to 0$ at the origin, so it never finishes the job (the circle has no corners).

(d) $\theta_0$ is a baseline, not a feature weight. Penalising it destroys shift-equivariance — add a constant to every $y$ and the fitted intercept is pulled back toward 0, biasing every prediction low — and it makes $\lambda \to \infty$ give $h \equiv 0$ instead of $h \equiv \bar y$.

(e) $\lambda \to 0$ gives OLS; $\lambda \to \infty$ gives the constant predictor $\bar y$. Features must be standardized because the penalty depends on the units of each feature, so without it $\lambda$ means something different in every coordinate.

Why this is the exam version of this idea

Trap 1 — assuming the two regularizers always agree. They are different objectives. These numbers are chosen so that each picks the vector the other rejects, which is the cleanest possible demonstration that "regularization shrinks weights" is not a complete description.

Trap 2 — "LASSO gives smaller weights". Not pointwise: $\theta_A$'s largest weight is $3$, bigger than either of $\theta_B$'s. LASSO gives sparser weights, i.e. fewer nonzero ones. Sparse and small are different properties.

Trap 3 — squaring the sum instead of summing the squares. $(3+0)^2 = 9$ agrees with $3^2 + 0^2 = 9$ by luck on $\theta_A$, but for $\theta_B$ it gives $(2+2)^2 = 16$ instead of $8$ — and reverses the conclusion. $\|\theta\|_2^2 = \sum_j\theta_j^2$.

Trap 4 — forgetting that $\lambda$ cannot be fitted. $\lambda$ is a hyperparameter. Minimising the training objective over $\theta$ and $\lambda$ jointly always returns $\lambda = 0$, since the penalty only ever adds to the objective. Hyperparameters live on held-out data by necessity, not by convention.

You have 1000 labelled examples and you want to choose the regularization strength $\lambda$ from the $C = 5$ candidates $\{0.01,\ 0.1,\ 1,\ 10,\ 100\}$. You run 5-fold cross-validation on the 1000 examples; each fold is 200 examples. The validation MSE for each $(\lambda, \text{fold})$ pair:

  2. (b) Suppose instead you had done a single 80:20 holdout, and your holdout split happened to be fold 1. Which $\lambda$ would you have chosen? What does the discrepancy demonstrate?
  3. (c) How many model fits does each procedure cost, including the final one? Give the general formula.

Step 1 — What are we actually being asked?

Cross-validation is a procedure for estimating a model's risk without touching the test set, used here as the scoring function in a search over 5 candidate values of a hyperparameter. So separate the three roles cleanly, because every confusion in this topic is a collapse of two of them:

  • Training set — fits $\theta$ (the parameters), by ERM.
  • Validation set(s) — scores $\lambda$ (the hyperparameter). Used repeatedly, therefore no longer unbiased for the final model.
  • Test set — estimates the risk of the one finished model. Used once, at the end, or not at all.

In $k$-fold, the 1000 examples take turns playing training and validation: for each fold, train on the other $k-1$ folds (800 examples) and score on the held-out one (200). Each example is validated on exactly once and trained on $k-1$ times.

Step 3 — (b) what a single split would have told you

Read down the fold-1 column alone: $0.42,\ \mathbf{0.20},\ 0.22,\ 0.30,\ 0.52$. The minimum is at $\lambda = \mathbf{0.1}$, not $\lambda = 1$.

A single 80:20 holdout would have selected $\lambda = 0.1$ — the wrong value, as judged by the far more reliable 5-fold estimate. And nothing in that one column would have warned you: $0.20$ versus $0.22$ looks like a clear winner if you have only one number each.

What it demonstrates is variance in the estimate. A single 200-example validation set gives a noisy estimate of risk, and the noise ($\pm 0.06$ or so across folds here) is comparable to the real differences between neighbouring $\lambda$ values ($0.30$ vs $0.24$). Averaging $k$ folds cuts that noise down without needing any more data, and that is the entire reason $k$-fold exists.

Look at the $\lambda = 0.1$ row to see it directly: its folds run $0.20, 0.34, 0.26, 0.32, 0.38$ — a spread of $0.18$, which is three times the gap between the best and second-best mean. Any conclusion drawn from one of those five numbers is a coin flip. The $\lambda = 1$ row, by contrast, is $0.20$–$0.28$ and wins on four of the five folds.

Step 4 — (c) cost

Holdout: one fit per candidate, plus one final refit on all the data.

$$C + 1 = 5 + 1 = \mathbf{6}\ \text{fits}$$

$k$-fold: $k$ fits per candidate, plus the final refit.

$$Ck + 1 = 5 \times 5 + 1 = \mathbf{26}\ \text{fits}$$

So $k$-fold costs about $k$ times more compute and buys you a $k$-times-averaged estimate. The extreme is LOOCV, $k = N$: here that would be $5 \times 1000 + 1 = 5001$ fits, each on 999 examples. Nearly unbiased, almost always too expensive, and with high variance of its own because the $N$ training sets are nearly identical. $k = 5$ or $10$ is the standard compromise.

If you were tuning two hyperparameters on a grid — say 5 values of $\lambda$ and 4 polynomial degrees — then $C = 20$ and 5-fold costs $101$ fits. The cost is multiplicative in the number of hyperparameters, which is why grid search gets abandoned quickly.

Step 5 — (d) and (e)

(d) You are choosing $\lambda$, a hyperparameter — a knob that controls the hypothesis class itself (here, how strongly weights are penalised, and so how much effective capacity the model has). The parameters $\theta$ are not being chosen here; they are refitted from scratch inside every one of the 25 fits.

Why not minimise training error over $\lambda$? Because the training objective is $\hat R(\theta) + \lambda r(\theta)$, and the training error $\hat R$ alone is minimised by whichever $\lambda$ constrains $\theta$ least — i.e. $\lambda = 0$, always, for every dataset. The answer would be a foregone conclusion and would have nothing to do with the data. The same argument applies to every capacity hyperparameter: more capacity always fits the training set at least as well, so training error ranks capacity monotonically and cannot find an optimum. A quantity that controls capacity cannot be tuned on the data used to fit the parameters.

(e) Having chosen $\lambda = 1$, refit on all 1000 examples with $\lambda = 1$. That is the shipped model, and it is the "$+1$" in the fit counts above. Each CV fit used only 800 examples, so none of those 25 models is the one you want — they existed only to score $\lambda$.

The separate test set — data that took part in neither the fitting nor the selection — exists to estimate the final model's risk. You need it because $0.24$ is optimistically biased: it is the minimum of five noisy estimates, and taking a minimum over noise systematically understates the truth. Report $0.24$ as "the CV score that selected $\lambda$", and whatever the untouched test set says as "the estimated risk". Peek at the test set repeatedly and it quietly becomes a validation set, after which you no longer have an honest estimate of anything.

Solution

(a) Means $0.44,\ 0.30,\ \mathbf{0.24},\ 0.34,\ 0.52$; 5-fold CV selects $\lambda = 1$.

(b) A holdout equal to fold 1 would select $\lambda = 0.1$ (its $0.20$ beats $\lambda=1$'s $0.22$) — the wrong value. It demonstrates that a single split gives a high-variance risk estimate, with fold-to-fold noise as large as the real differences between candidates; averaging $k$ folds removes it without extra data.

(c) Holdout $C + 1 = 6$ fits; $k$-fold $Ck + 1 = 26$ fits; LOOCV would be $CN + 1 = 5001$.

(d) The hyperparameter $\lambda$. Training error cannot choose it because training error is minimised at $\lambda = 0$ for any dataset — capacity-controlling quantities are monotone in training error and so have no interior optimum there.

(e) Refit on all 1000 examples at $\lambda = 1$. A separate, never-selected-on test set gives the honest risk estimate, because the winning CV score $0.24$ is biased low by being the minimum over five noisy numbers.

Why this is the exam version of this idea

Trap 1 — picking per-fold winners and voting. CV selects on the mean across folds, one number per candidate. Choosing a different $\lambda$ for each fold produces five models and no decision.

Trap 2 — forgetting the final refit. People answer "25 fits" and ship one of the 800-example fold models. The procedure is: score with CV, then retrain on everything with the chosen hyperparameter. $Ck + 1$, and the $+1$ is the model you actually deploy.

Trap 3 — reporting the CV score as the test error. $0.24$ is the minimum over five candidates of noisy estimates, which is biased low by construction. This is the same selection bias as in Problem 27(b), where picking a model on the test set stopped that test set from being honest.

Trap 4 — confusing $k$ with the number of candidates. $k$ is the number of folds (how the data is cut), $C$ is the number of hyperparameter values (what you are searching). Here both are 5, which is exactly the sort of coincidence an exam uses to see whether you know which is which. If the question changes to 10-fold over 5 candidates, the answer is $51$ fits, not $26$ or $101$.

Trap 5 — "$k$-fold gives more data". It gives better use of the data you have. Every fit still sees only $\frac{k-1}{k}N = 800$ examples; what improves is the precision of the estimate, by averaging, not the size of any training set.

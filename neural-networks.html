Part II · Chapter 13

Neural networks

You already know one neuron — it's logistic regression. This chapter stacks neurons into a network, counts its parameters, trains a three-neuron network by hand with the chain rule, and builds the multivariate chain rule that everything deeper depends on.

Fixes to the pre-reading

The Neural Networks pre-reading has a few slips; this chapter uses the corrected versions and flags each where it comes up:

  • A layer of $K$ neurons on $M$ inputs has $KM + K = K(M+1)$ parameters — the notes write "$KM + M$".
  • The 3-3-2-1 example sums to 23 ($12 + 8 + 3$); the notes' line says "Total: 21", though their own summary table says 23.
  • The three-neuron network's parameter list omits $w_{1,2}$ (it still correctly says 7 parameters).
  • In the logistic-regression derivative table, the bias line simplifies to $-\frac1N\sum(1-\hat y)$, which is only the $y = 1$ case; the general answer is $-\frac1N\sum(y - \hat y)$.
  • §2.2.3 ("Chain rule with multiple inputs") is cut off after its first paragraph.

1. Linear and logistic regression, redrawn as networks

A neural network's gradient is the same idea with longer products.

2. The neuron and its activation function

Definition

A neuron is a linear function followed by an activation function:

$$ z = b + \sum_j w_j x_j, \qquad a = g(z). $$

The activation $g$ is (almost) any nonlinear function. Logistic regression is a neuron with $g = \sigma$.

Activation$g(z)$$g'(z)$Notes
Logistic (sigmoid)$\frac{1}{1+e^{-z}}$$\sigma(z)(1-\sigma(z))$Output in $(0,1)$; saturates at both ends
ReLU (rectified linear unit)$\max(0, z)$$1$ if $z > 0$, else $0$"Takes the input and clamps negative values to zero." The modern default
Threshold (historic)$\1\{z \ge 0\}$$0$ almost everywhereThe original perceptron; untrainable by gradient descent
Figure 2 — one neuron, one input: shape the output
Solid = $a = g(wx + b)$; dashed = $\frac{da}{dx}$. What to notice: $b$ slides the "kink" to $x = -b/w$; the sign of $w$ decides which side is active. A ReLU neuron is a hinge you can place anywhere and point either way — the building block §3 uses. Pick "threshold" and the derivative is flat zero: no gradient to learn from. Pick "none" and the neuron is just linear regression.
Why the activation must be nonlinear

Stack two neurons with no activation: $w_2(w_1 x + b_1) + b_2 = (w_2w_1)x + (w_2b_1 + b_2)$ — still a line. Any stack of linear layers collapses into a single linear layer, so depth buys nothing. The nonlinearity is what lets a network represent curves.

3. A three-neuron network

The notes' example: predict traffic volume from time of day. The data rises through the morning and falls through the evening, so a line in $x_1$ alone won't do. You've seen one fix — engineer $x_2 = x_1^2$ and fit a quadratic with linear regression (chapter 10). Here's the other: two ReLU neurons, one to model the morning's upward trend and one the evening's downward trend, and a third that combines them.

Linear regression + quadratic feature $$ \hat y = b + w_1 x_1 + w_2 x_1^2 $$

$w_1, w_2, b$ — 3 parameters. You chose the feature $x_1^2$.

Three-neuron network $$ a_{1,j} = g_{\text{ReLU}}(b_{1,j} + w_{1,j}x_1),\quad j = 1, 2 $$ $$ \hat y = b_{2,1} + w_{2,1}a_{1,1} + w_{2,2}a_{1,2} $$

$w_{1,1}, b_{1,1}, w_{1,2}, b_{1,2}, w_{2,1}, w_{2,2}, b_{2,1}$ — 7 parameters. The network learns its own features $a_{1,1}, a_{1,2}$.

Figure 3 — train the three-neuron network (the centrepiece)
Data is synthetic (30 hours, rising 5–9 am, then a slow decline), with hour rescaled to $x_1 = (h - 14)/4.5$. Violet = network output; the dashed curves are the two hidden neurons' contributions $w_{2,j}a_{1,j}$ — each is a hinge. Grey = the quadratic-feature linear regression, fitted in closed form. What to notice: (1) the network's output is two hinges plus a constant — it can bend in exactly two places, which is why it can put the corner at 9 am while the parabola can't. (2) Press "New random start" repeatedly and train each time: the final loss depends on where you start. Some starts end with a neuron "dead" (its $z$ is negative on every data point, so ReLU passes zero gradient and it never recovers). Unlike logistic regression, this objective is not convex. (3) Push $\alpha$ toward 1.5 and training diverges.

In the code that drives Figure 3, starts #1–#20 (the one shown on load plus the next 19 presses of "New random start"), each trained 3000 steps at $\alpha = 0.1$, ended with MSE ranging from $0.0018$ to $0.0315$; 8 of the 20 finished above $0.02$, most of them with a dead neuron. The good fits all put one hinge at about 9 am. The quadratic regression's MSE is $0.0090$ — and it is the same every time, because its objective is convex with a closed-form solution.

The derivatives, by the chain rule

Use squared error and one training point ($N = 1$), so $J = (y - \hat y)^2$ and $\frac{\partial J}{\partial\hat y} = -2(y - \hat y)$. Follow each parameter's path to the output and multiply the local derivatives along it:

ParameterChainEvaluates to
$b_{2,1}$$\frac{\partial J}{\partial\hat y}\frac{\partial\hat y}{\partial b_{2,1}}$$-2(y-\hat y)\cdot 1$
$w_{2,j}$$\frac{\partial J}{\partial\hat y}\frac{\partial\hat y}{\partial w_{2,j}}$$-2(y-\hat y)\cdot a_{1,j}$
$b_{1,j}$$\frac{\partial J}{\partial\hat y}\frac{\partial\hat y}{\partial a_{1,j}}\frac{\partial a_{1,j}}{\partial z_{1,j}}\frac{\partial z_{1,j}}{\partial b_{1,j}}$$-2(y-\hat y)\cdot w_{2,j}\cdot \1\{z_{1,j} > 0\}\cdot 1$
$w_{1,j}$$\frac{\partial J}{\partial\hat y}\frac{\partial\hat y}{\partial a_{1,j}}\frac{\partial a_{1,j}}{\partial z_{1,j}}\frac{\partial z_{1,j}}{\partial w_{1,j}}$$-2(y-\hat y)\cdot w_{2,j}\cdot \1\{z_{1,j} > 0\}\cdot x_1$

Every update is then $\text{param} \leftarrow \text{param} - \alpha\,\frac{\partial J}{\partial\,\text{param}}$ — the same SGD rule as always, just applied to 7 parameters.

Read the chain as a story

$\frac{\partial J}{\partial w_{1,j}}$ = (how wrong the output is) × (how much the output listens to neuron $j$) × (is neuron $j$ switched on?) × (how big the input was). If the neuron is off ($z_{1,j} \le 0$), the whole product is zero — that's the dead-ReLU effect from Figure 3, written as algebra.

Guided problemOne SGD step through the network, by hand

Parameters: $w_{1,1} = 1,\ b_{1,1} = -1,\ w_{1,2} = -1,\ b_{1,2} = 3,\ w_{2,1} = 2,\ w_{2,2} = 1,\ b_{2,1} = 0.5$. One training point $x_1 = 2$, $y = 4$. Squared error. Compute the forward pass, the loss, all 7 gradients, and one SGD step with $\alpha = 0.02$. Did the loss go down?

Step 1 — Forward pass

$z_{1,1} = 1\cdot 2 - 1 = 1$, $a_{1,1} = 1$. $z_{1,2} = -1\cdot 2 + 3 = 1$, $a_{1,2} = 1$.

$\hat y = 0.5 + 2(1) + 1(1) = 3.5$. Loss $J = (4 - 3.5)^2 = 0.25$.

Step 2 — The shared factor

$\frac{\partial J}{\partial\hat y} = -2(4 - 3.5) = -1$. Every gradient starts with this. Both neurons are on ($z > 0$), so both ReLU factors are $1$.

Answer & the takeaway

Loss fell from $0.25$ to $0.00436$. Two lessons. (1) Layer-1 gradients are bigger here ($-4$ for $w_{1,1}$) because they're multiplied by the downstream weight and the input — early layers can be very sensitive. (2) The step size matters a lot: with $\alpha = 0.1$ the same gradients overshoot to $\hat y = 6.45$ and a loss of $6.0025$ — 24× worse than where you started. (3) Now suppose instead $x_1 = 4$: then $z_{1,2} = -1\cdot 4 + 3 = -1 < 0$, neuron 2 is off, and all of $w_{1,2}, b_{1,2}$'s gradients are zero for that point.

4. Fully connected networks

Once you can build three neurons, you can build any number. A fully connected network organizes neurons into $L$ layers, and each neuron in a layer takes every output of the previous layer as input (the first layer takes every input feature). If the previous layer has $M$ values, each neuron's linear function has $M$ inputs.

Figure 4 — architecture and parameter count
Up to 8 nodes per layer are drawn; wider layers are shown with "⋮". What to notice: the count is dominated by the widest pair of adjacent layers — for a 28×28 image classifier, almost all parameters live in the first layer.
Notation — $w_{\text{layer},\,\text{output},\,\text{input}}$ and $b_{\text{layer},\,\text{output}}$

$w_{2,1,3}$ is the weight in layer 2, going into neuron 1 of that layer, from neuron 3 of the previous layer. The model for the notes' 3-3-2-1 network, layer by layer:

$$ a_{1,i} = g(z_{1,i}),\quad z_{1,i} = b_{1,i} + \sum_j w_{1,i,j}\,x_j $$ $$ a_{2,i} = g(z_{2,i}),\quad z_{2,i} = b_{2,i} + \sum_j w_{2,i,j}\,a_{1,j} $$ $$ \hat y = a_{3,1} = g(z_{3,1}),\quad z_{3,1} = b_{3,1} + \sum_j w_{3,1,j}\,a_{2,j} $$

Substituted into one line: $\hat y = g\Bigl(b_{3,1} + \sum_k w_{3,1,k}\,g\bigl(b_{2,k} + \sum_i w_{2,k,i}\,g(b_{1,i} + \sum_j w_{1,i,j}x_j)\bigr)\Bigr)$. Nested functions — which is why the derivatives will be long chain rules.

Counting parameters

A neuron with $M$ inputs has $M$ weights and $1$ bias. A fully connected layer of $K$ neurons on $M$ inputs therefore has

$$ \underbrace{KM}_{\text{weights}} + \underbrace{K}_{\text{biases}} = K(M+1) \text{ parameters.} $$
Correction

The notes write "$KM + M = K(M+1)$". The middle expression is a typo: there is one bias per neuron, so $K$ of them, not $M$. ($KM + M = M(K+1)$, which isn't equal to $K(M+1)$ unless $K = M$ — which is why the error is invisible in the notes' 3-input, 3-neuron first layer.)

5. Derivatives in a deeper network

The notes show just the bias derivatives for the 3-3-2-1 network ("less crazy indexing"):

$$ \frac{\partial J}{\partial b_{3,1}} = \frac{\partial\ell}{\partial\hat y}\frac{\partial a_{3,1}}{\partial z_{3,1}}\frac{\partial z_{3,1}}{\partial b_{3,1}} $$ $$ \frac{\partial J}{\partial b_{2,i}} = \frac{\partial\ell}{\partial\hat y}\frac{\partial a_{3,1}}{\partial z_{3,1}}\frac{\partial z_{3,1}}{\partial a_{2,i}}\frac{\partial a_{2,i}}{\partial z_{2,i}}\frac{\partial z_{2,i}}{\partial b_{2,i}} $$ $$ \frac{\partial J}{\partial b_{1,i}} = \frac{\partial\ell}{\partial\hat y}\frac{\partial a_{3,1}}{\partial z_{3,1}}\frac{\partial z_{3,1}}{\partial \mathbf a_{2}}\frac{\partial \mathbf a_{2}}{\partial \mathbf z_{2}}\frac{\partial \mathbf z_{2}}{\partial a_{1,i}}\frac{\partial a_{1,i}}{\partial z_{1,i}}\frac{\partial z_{1,i}}{\partial b_{1,i}} $$

Look at the last line: the middle factors are in bold — vectors. Why? Because $b_{1,i}$ affects $a_{1,i}$, and $a_{1,i}$ feeds both layer-2 neurons. There are two paths from $b_{1,i}$ to $\hat y$. The single-variable chain rule, which multiplies along one path, isn't enough. The notes: "as we start to have cycles in our network diagram" (they mean paths that split and rejoin) "we'll need the multivariate chain rule." That's §6.

6. The chain rule on computation graphs

6.1 One path: multiply along the edges

For $h(x) = f(g(x))$, the chain rule is $\frac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$, or in Leibniz notation $\frac{df}{dx} = \frac{df}{dg}\frac{dg}{dx}$. Draw the computation as a graph $x \to g \to f$ and write each edge's local derivative on it: $\frac{dg}{dx}$ on the first edge, $\frac{df}{dg}$ on the second. The derivative of the output with respect to the input is the product of the edge derivatives along the path. It extends to any depth:

$$ h(x) = f_4(f_3(f_2(f_1(x)))) \quad\Longrightarrow\quad \frac{df_4}{dx} = \frac{df_4}{df_3}\frac{df_3}{df_2}\frac{df_2}{df_1}\frac{df_1}{dx}. $$

6.2 Several paths: sum over them

Now $h(x) = f(g_1(x), g_2(x))$ with $g_1, g_2 : \R\to\R$ and $f : \R^2 \to \R$. $x$ feeds both $g$'s, so there are two paths from $x$ to the output. Each path's product is one way $x$ influences $h$; the total influence is their sum:

$$ \frac{dh}{dx} = \frac{\partial f}{\partial g_1}\frac{dg_1}{dx} + \frac{\partial f}{\partial g_2}\frac{dg_2}{dx}. $$
Multivariate chain rule

For $f:\R^n\to\R$ and $g_1,\dots,g_n:\R\to\R$, $$ \frac{d}{dx}f\bigl(g_1(x),\dots,g_n(x)\bigr) = \sum_{i=1}^{n}\frac{\partial f}{\partial g_i}\frac{dg_i}{dx}. $$ Multiply along each path, then add over paths. The one-path rule is the $n = 1$ case.

Figure 5 — two paths, checked numerically
$g_1 = x^2$, $g_2 = \sin x$, $f = g_1 g_2$, so $h(x) = x^2\sin x$. The last line estimates $h'(x)$ by a finite difference, $\frac{h(x + 10^{-6}) - h(x)}{10^{-6}}$, independently of the chain rule. What to notice: the sum over both paths matches it at every $x$. Tick "forget the second path" — the mistake of multiplying along only one path — and the answer is wrong almost everywhere.
Try itTwo paths by hand

$h(x) = f(g_1(x), g_2(x))$ with $g_1 = x^2$, $g_2 = \sin x$, $f(u, v) = uv$. Find $h'(1)$ using the multivariate chain rule.

Step 1 — Edge derivatives

$\frac{dg_1}{dx} = 2x = 2$. $\frac{dg_2}{dx} = \cos x = \cos 1 = 0.5403$. $\frac{\partial f}{\partial g_1} = g_2 = \sin 1 = 0.8415$. $\frac{\partial f}{\partial g_2} = g_1 = 1$.

Step 2 — Multiply along, add across
$$ h'(1) = (0.8415)(2) + (1)(0.5403) = 1.6829 + 0.5403 = 2.2232. $$
Answer & the takeaway

$2.2232$ — and the product rule on $x^2\sin x$ gives $2x\sin x + x^2\cos x = 2.2232$ too. The product rule is the multivariate chain rule for $f(u,v) = uv$. A finite difference with step $10^{-6}$ gives $2.2232$ as well.

6.3 Vector form

Stack the inner functions into one vector-valued function $\mathbf g(x) = [g_1(x), \dots, g_n(x)]^\top$, so $h(x) = f(\mathbf g(x))$ — the graph now has one path through a vector node. In denominator layout, $\frac{\partial\mathbf g}{\partial x} = \bigl[\frac{\partial g_1}{\partial x}\ \cdots\ \frac{\partial g_n}{\partial x}\bigr]$ (a row) and $\frac{\partial f}{\partial\mathbf g} = \bigl[\frac{\partial f}{\partial g_1}, \dots, \frac{\partial f}{\partial g_n}\bigr]^\top$ (a column). Multiplying along the single edge-path:

$$ \frac{d}{dx}f(\mathbf g(x)) = \frac{\partial\mathbf g}{\partial x}\,\frac{\partial f}{\partial\mathbf g} = \sum_{i=1}^n \frac{\partial f}{\partial g_i}\frac{dg_i}{dx}, $$

— a dot product, which is exactly the sum over paths. Same computation, same derivative, but now written with vectors, which is how the bold $\partial\mathbf a_2/\partial\mathbf z_2$ factors in §5 are handled.

Common mistake

Once derivatives are vectors and matrices, order matters. In denominator layout the chain runs inner-to-outer, left to right ($\frac{\partial\mathbf g}{\partial x}\frac{\partial f}{\partial\mathbf g}$); numerator layout runs the other way. Pick one layout, stick with it, and check that the shapes of every product line up.

The notes' §2.2.3 ("chain rule with multiple inputs" — vector inputs and vector outputs) stops after its opening paragraph, which says only that the general case is repeated application of the rule above. It will presumably be covered in lecture.

7. Recap

  1. A neuron = linear function + nonlinear activation. Logistic regression is one neuron.
  2. Activations: sigmoid, ReLU $\max(0,z)$; the historic threshold (perceptron) has zero gradient. Without nonlinearity, layers collapse to one linear map.
  3. Three-neuron traffic network: two ReLU hinges + a combining neuron, 7 parameters, vs 3 for linear regression with $x_1^2$. The network learns its features; its objective is not convex, so the result depends on initialization.
  4. Fully connected: every neuron sees every output of the previous layer. Notation $w_{\text{layer,output,input}}$.
  5. A layer of $K$ neurons on $M$ inputs has $K(M+1)$ parameters; 3-3-2-1 has $12 + 8 + 3 = 23$.
  6. Output layer / hidden layers; the "input layer" is data, not neurons. Fully connected = linear = dense; MLP.
  7. Gradients: multiply local derivatives along each path from parameter to loss; sum over paths when paths split (multivariate chain rule); in vector form, a dot product.
